### 읽기

1. **J5는 블록 방향을 거의 1:1로 돌린다**(기울기 1.10~1.14°/°). J5 60 → d −30.7°, 90 → +2.6°, 120 → +35.6°. 가설(J5로 블록 yaw를 맞춘다)이 자료와 맞는다. 단 J5는 60·90·120 세 수준뿐이라 중간값의 선형성은 확인하지 못했다.
2. **J5 90 고정에서 놓인 블록 방향은 퍼진다**: 표준편차 5.7°, 범위 −5.6~+10.5°. 이 정도면 |d| > 5°가 약 4할이다. 연쇄에서 팔이 놓은 읽기 4개 중 2개가 5°를 넘은 것과 맞는다.
3. 같은 셀을 반복해 놓았을 때의 방향 표준편차(셀 안)는 **2.5°**다. J5 90 전체 5.7°가 이보다 큰 것은 셀(J1·r)마다 평균이 다르기 때문이다(포즈 단위 LOO로 J1·r행을 넣으면 5.9°에서 3.9°). **주의: J5 90 포즈는 4개뿐**(c00, c02, cal03, cal09)이고 J1 110·먼 행은 c02 하나라, J1·r 항은 매우 적은 포즈에 기대고 있다.
4. **chain-002의 13.8°는 이상치가 아니라 예측 가능한 쪽이었다.** 모델(J5+J1+r)은 자리 (r_index 8, J1 104), J5 90에서 d = **+8.4°**를 예측한다. CH-1 chain-002는 +14.5°(잔차 +6.0°), CH-0 chain-002는 +2.6°(잔차 −5.9°)였다. 연쇄에서 팔이 놓은 4개 읽기의 모델 잔차는 −5.9, −1.7, +6.0, −7.0°(표준편차 약 5°)로 **셀 안 표준편차 2.5°보다 크다.** 즉 J5 90 고정에서 손 yaw의 J1·r 의존(예측 가능한 부분)과, 놓는 순간 블록이 손에 대해 돌아가는 부분(예측 불가, 약 ±5~7°)이 모두 있다. 앞선 초안의 「분포 밖」 해석과 이슈 보고서의 「원인 미확인」을 이에 맞게 고친다.
- **40자리 목록의 예측**: 예측 d가 5°를 넘는 자리 8개, 셀 안 2.5°를 더한 |d|>5° 기대 비율 **0.29**. CH-1의 정지는 시작 전에 예측할 수 있었다. 판정에 쓴 방향 기준(반경선)이 손 yaw의 대리값이라 J1 110 쪽에서 실제 손과 약 6~8° 어긋난다.
5. 위치(포즈 단위 LOO, J5 그룹별): J5 60 횡방향 RMS 1.9 mm·반경 3.7 mm, J5 120 횡방향 2.2 mm·반경 4.0 mm, J5 90(포즈 4개) 횡방향 1.4 mm·반경 2.4 mm. **J5 ≠ 90에서 횡방향 오차가 눈에 띄게 나쁘지는 않다**(RMS 2.0 mm, 창 6.48 mm 안). 단 J5 90 포즈가 4개뿐이라 비교는 약하고, 모든 실기 성공은 J5 90이었다. 아울러 J5 60↔120이 블록 영상 위치를 약 9 mm 바꾼다는 기존 결과(`docs/*명령-셀-블록-영상-위치-맵-분석.md`)가 있고 L1 맵은 J5 선형항을 이미 갖는다(교차 검증 du 2.03·dv 4.16 화소). J5 정렬을 쓰려면 그 J5 항의 정확도가 필요하고, J5 ≠ 90 훈련 점은 30개뿐이다.

한계: 방향 측정은 영상에서 최소 외접 사각형 각도라 측정 잡음이 있다(같은 상태 사진이 4.5°와 5.5°로 읽힘). d의 LOO에는 놓기 흩어짐(셀 안 2.5°)이 섞여 있어 손 yaw 모델 오차의 상한이다.

## 2. J5 정렬 계획 (초안, 승인 대기)

**목표**: 놓인 블록의 측정 방향 d(부호 있음)에 맞춰 J5를 정해, 사람 개입 없이 |ψ| ≤ 5°를 유지하며 집는다. 성공 판정과 36/40 판정은 바꾸지 않는다. 방향 기준의 재정의는 2.1에 사전 규칙 이탈로 기록했다.

### 2.1 규칙 (쓰기 0, 코드)

**사용자 제안(2026-11-11)**: 「블록이 놓아진 방향으로 파지할 때 손등의 각도를 맞추면 다시 내려놓았을 때와의 편차를 줄일 수 있다.」 위 분석과 맞는다. 블록이 손에 대해 어떤 각도로 쥐이는지가 놓일 때의 방향을 정하므로(J5 90에서 손 yaw 예측 +8.4°, 측정 +14.5°), 집을 때 J5로 손을 블록에 맞추면 쥠 각도 오프셋이 작아지고(턱이 블록을 돌리지 않음), 놓을 때 J5로 손을 그 자리의 반경선에 맞추면 놓인 블록이 반경선에 가깝게 놓인다. 두 쪽을 모두 쓴다.

- **집기 정렬**: 측정 (du, dv, 블록 각도) → J5 = round(90 + (d − d0(J1, r)) / k)(d는 부호 있는 반경 대비 블록 각도, d0·k는 위 적합식), 그 J5로 순방향 맵의 J5 항을 써서 (J1, r)를 역변환. J5와 (J1, r)가 서로 영향을 주므로 2~3회 고정점 반복.
- **놓기 정렬(사용자 제안 반영)**: 놓을 자리 B의 J5_B = round(90 − d0(J1_B, r_B) / k)로 손 yaw를 B의 반경선에 맞춰, 놓인 블록의 예측 d를 0 근처로 한다. 다음 집기의 J5가 90 근처가 되어 J5 보정량이 줄고 J5 ≠ 90 위치 오차 영향도 준다.
- **범위**: J5는 표가 허용하는 60~120(`config/workspace.yaml` `j5_deg: [60, 120]`, G0a로 확정). 보정이 이 범위를 넘으면(약 ±33°) **J5를 잘라 쓰지 않고 시도를 거절**한다(잘린 J5는 정렬이 안 된 하강이다). 정렬 후 예상 잔여 ψ가 5° 이하일 때만 시도한다.
- **방향 기준 재정의(사전 규칙 이탈로 기록)**: 판정 문턱 5°는 그대로이지만, 기준이 **반경선에서 손 yaw 예측(J5 정렬 후의 손 방향)** 으로 옮겨 간다. 반경선은 손 yaw의 대리값이었고 J1 110 쪽에서 6~8° 어긋난다(P1 p1-01의 「그리퍼 각도와 블록 방향 불일치」 관찰과 일치). 새 정의는 **앞으로의 실행에만** 쓰고 P1·CH 기록은 다시 채점하지 않는다. P1 한계에 한 줄 추가: 높은 J1 쪽 시도는 보고한 ψ보다 실제 손과 더 어긋나 있었는데도 성공했다.
- 한계: 기울기 k는 영상 각도에서 구한 값이라 보드 위치에 따라 원근 때문에 달라질 수 있다(J1·r 항이 일부 흡수). J5는 60·90·120 세 수준에서만 측정했다.

### 2.2 검증 순서

1. **쓰기 0**: 기존 70장에서 「측정 d → J5 → 예측」을 가상으로 돌려 J5 정렬 후 잔여 ψ 분포를 모의한다(잔차는 LOO 3.3° 상한).
2. **쓰기 있음(승인 필요)**: 1단 sanity(2~3시도)로 J5 ≠ 90 하강·집기·내려놓기와 쓰기 수를 확인한다. J5 ≠ 90에서 하강 확인이 필요한지는 사용자 결정(처음 J5가 바뀌는 시도).
3. 본 실행: 연쇄 40시도, ψ 거절이 나면 J5 정렬 모델의 잔여 오차로 기록한다.

**사용자 결정 필요**: J5 ≠ 90 하강에 처음 한 번 확인을 받을지(이전 승인에는 「J5≠90 금지」가 있었으므로 새 승인 범위가 필요하다). 권고: 첫 J5 ≠ 90 하강 한 번만 확인(이 실행의 첫 집기 확인과 합침).

### 2.3 하지 않는 것

ψ 문턱 완화, 같은 블록 재촬영으로 통과시키기, 성공 판정과 36/40 판정 변경, P1·CH 재채점. P1 20시도 완성.

### 2.4 위험

| 위험 | 대응 |
| --- | --- |
| J5 중간값의 선형성 미확인(60·90·120뿐) | 2.2의 sanity에서 한 번 확인, 어긋나면 J5 수준을 60·90·120으로 제한 |
| J5 ≠ 90에서 위치 맵 오차 증가 | 포즈 단위 LOO 횡방향 RMS 2.0 mm로 J5 90보다 크게 나쁘지 않음(위 읽기 5). 실기 sanity에서 확인 |
| 놓는 순간 블록이 손에 대해 돌아가는 부분(약 ±5~7°, 예측 불가) | 집기·놓기 정렬로 쥠 오프셋을 줄여도 남을 수 있다. 정렬 후 잔여 ψ를 기록하고 거절 비율을 보고 |
| 하강 확인 면제와 J5 변경의 상호작용 | 사용자 결정 필요 |
