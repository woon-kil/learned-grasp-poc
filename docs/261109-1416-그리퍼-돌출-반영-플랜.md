# 그리퍼 돌출 반영 플랜

작성: 2026-11-09 14:16 KST. 장치 명령 0건. 사용자가 세 항목 진행을 요청했다.

## 목표

DOFBOT 그리퍼의 구조적 돌출을 G0b 전에 정본 플랜, 런북, 안전 코드에 반영한다.

## 현재 상태 (As-Is)

돌출 계산(`docs/261109-1257-그리퍼-돌출-계산.md`)이 정본 플랜, 런북, 안전 코드에 없다. 「17.5 mm 아래에서 닫지 않는다」는 `session.fit_config`의 허용값 목록으로만 강제되므로, `z_grasp_mm`를 낮춘 구성은 `replay` 경로에서 막히지 않을 수 있다. 안전 검사(`safety.py`)는 close를 grasp 자세에서만 허용할 뿐 높이를 보지 않는다.

## 목표 상태 (To-Be)

17.5 mm 미만의 파지 높이로는 구성 객체를 만들 수 없다. 플랜은 닫은 손끝 기준을 말하고, 런북은 G0b 첫 통과에서 볼 항목을 말한다. 표와 판정 수치는 그대로다.

## 접근 방법

| 안 | 장점 | 단점 | 판단 |

| `TableSpec.__post_init__` | YAML, `replace`, 테스트 경로를 한 곳에서 막는다 | 낮은 z의 표를 분석용으로도 못 만든다 | **채택** |

## 외부 자료

Helma·Datseris(1986, [URI 공개 기록](https://digitalcommons.uri.edu/mcise_facpubs/154))는 일반 평행 그리퍼의 손끝이 닫힐 때 작업면 쪽으로 움직여 작은 물체를 잡으려면 팔 보정이 필요하다고 적는다. 초록 수준의 2차 확인이고 DOFBOT 값은 아니다. 돌출을 장치 고유 구조로 다루고 팔 높이로 보정한다는 방향과 맞는다. 수치는 이 프로젝트의 계산과 관찰만 쓴다.

## 변경

1. **`src/learned_grasp/config.py`**: `MIN_Z_GRASP_MM = 17.5`를 두고 `TableSpec.__post_init__`에서 유한값이 아니거나 미만이면 `ConfigError`를 낸다. 파일 로드뿐 아니라 `dataclasses.replace`로 만드는 경로(`ladder_config`, `fit_config`)도 같이 막기 위해 `load_config`가 아니라 `TableSpec`에 둔다.
2. **`tests/test_safety.py`**: 경계 테스트(17.5 통과, 17.4·NaN·무한대 거부, YAML 파싱 경로, `replace` 경로, `fit_config`의 17.5 유지)를 추가한다.
3. **정본 플랜 v2.2**: §5에 돌출과 닫은 손끝 기준을 추가하고, 그리퍼 행의 근거를 고친다. 판정 수치는 바꾸지 않는다.
4. **`docs/G0-RUNBOOK.md`**: G0a에 연 상태 드라이런의 한계를 적고, G0b에 첫 통과 관찰 항목(위치별 닫은 손끝과 작업대 접촉, 놓을 때 블록 끌림, 들고 이동할 때 간격)을 넣는다. 코드와 달라진 ladder 설명(`+60…0`, 단계당 5회 → `(15, 5, 0)`, 단계당 25회)도 고친다.
5. **`PROJECT-STATUS.md`**: R12 처리와 테스트 수를 갱신한다.

## 보장 범위

이 검사는 `TableSpec`의 **명목 높이**만 막는다. 현재 `session`과 `g0_runner`처럼 구성에서 표를 생성하는 경로에 적용된다. 다음은 보장하지 않는다.

- `PoseTable(entries)`나 `PoseTable.load()`로 만든 표를 `SafetyGate`에 넘기는 경로. 게이트는 구성과 표의 일치를 검사하지 않는다. 현재 실행 명령은 이 경로를 쓰지 않는다.
- 실제 FK 높이. 17.5 mm 구성도 `z_tol_mm`만큼 아래일 수 있다.
- 닫은 손끝의 안전. 17.5 mm 닫기는 시험하지 않았다.

## 범위 밖

- 표와 구성의 일치 검사: 현재 실행 경로에 필요 없다. 표 파일을 실행 입력으로 쓰게 되면 그때 넣는다.
- `close_sdk` 147 재판단: G0b에서 한다.
- 닫은 손끝의 실측, 겹침 불일치 원인 규명: 측정 방법이 먼저 필요하다.
- 하한을 표의 z 허용 오차(±1 mm)까지 포함한 실제 FK 값으로 검사하는 것: 하한은 명목값 기준이다. 구성 3은 21.65~22.61 mm라 이번에는 영향이 없다.
- 하한 값 변경: 17.5는 닫은 손끝이 작업대 위 약 2~6 mm라는 추정에서 온 값이고 실측이 아니다.
