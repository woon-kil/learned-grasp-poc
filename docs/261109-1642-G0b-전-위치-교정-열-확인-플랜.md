## 세션 1: `G0b-5-r{N}` 다른 위치 빈 손 닫기

블록 없음. 위치마다 폴더와 승인 파일을 따로 둔다. 각 위치 **+15 → +5 → 0**, 단계마다 `close-check --r-index N --z-offset O --hold-sec 20 --start-confirmed`, 쓰기 7회, 위치당 21회, 위치별 `max_writes` 22, **3곳 합계 상한 66회**. 단계 사이 60초 이상. 승인은 한 번에 받되 범위에 세 폴더와 합계를 적는다.

| r_index | 선택 이유 | r | 0 단계 모델 z, 기울기 |
| --- | --- | --- | --- |
| 2 | 표에서 모델 z 최저 | 129.7 | 19.03, 5° |
| 0 | r 작은 끝 | 119.8 | 20.07, 3° |
| 9 | r 큰 끝 | 165.1 | 19.67, 10° |

- J1 90, J5 90. **J1, J5 전체의 여유를 대표하지 않는다.**
- 내려갈 조건은 간격 − FK 하강량 ≥ 3 mm이고, 위치별 하강량을 실행 전에 계산해 조건을 적는다. 사용자에게는 조건 수치만 알리고 **읽기 전에 예상 간격을 말하지 않는다.**
- 자를 고정해 세운다. 판독 오차는 앞 세션에서 정량화하지 못했으므로 추정이면 추정으로 기록한다. 판독 불가나 조건 미달은 그 위치 실패다. **재실행하지 않는다.** 앞 세션의 +15 반복은 예외였고 반복하지 않는다.
- 0 단계 뒤 관찰로 접촉 없음을 기록해야 그 위치 통과다.
- 접촉, 이상음, 냄새, 떨림, 30초 타이머는 앞 플랜대로 전원 차단이고, 접촉이면 조임 탐색 중단이다.

### v3 변경: 눈금 판독 근거 제외 (r_index 0, 9는 방법 재결정 대기)

r_index 2 수행 중 사용자가 **DaBai 카메라에 가려 정확한 판독이 어렵다**고 보고했다. 그 위치의 판독은 +5 약 10 mm, 0 약 8 mm로 모델 하강량 5.79 mm와 맞지 않아, 판독 오차가 3 mm 여유보다 클 수 있다. **G0b-3과 r_index 2의 간격 값은 수치 근거로 쓰지 않는다.** 두 곳의 근거는 0 단계 접촉 없음이다.

종이 게이지안은 Codex 검토에서 BLOCKING 2건으로 **기각**했다. 텐트는 경사면 높이가 달라 「움직이지 않음 = 그 높이 이상」이 성립하지 않고, 설치·교체·회수에 손이 경로로 들어간다.

**대안(사용자 가능 여부 확인 전, 미승인)**: 작업대 높이에서 옆으로 찍는 고정 영상. 시작 전에 휴대폰과 자를 팔 경로 밖에 고정하고 프로그램이 도는 동안 손을 넣지 않는다. 판독은 끝난 뒤 영상으로 한다. DaBai에 가리지 않는 각도인지 시작 전에 확인하고, 가리거나 읽지 못하면 내려가지 않고 그 위치 실패다.

**현재 상태**: r_index 2 통과(접촉 없음, 쓰기 21회). r_index 0, 9 미실시. G0b 진입 보류.

**한 곳이라도 실패하면 G0b에 들어가지 않는다.** 그 위치를 표에서 빼거나 값을 바꾸는 구성 변경을 새 플랜으로 정한다.

### 사람 관찰과 판정의 분리

성공·실패는 판정 출력과 **독립된 사람 관찰**로 가른다. 사용자는 낙하·미끄러짐·안 집힘 등 **이상이 있던 시도만** 알려 준다. 끝난 뒤 시도별 전후 사진을 내가 대조해 함께 표에 적는다. 판정 출력과 관찰이 다르면 오판정으로 표시한다.

### 시도 결과별 처리

| 결과 | 처리 |
| --- | --- |
| 낙하, 접촉, 튐, 이상음, 냄새, 떨림 | 전원 차단, 세션 종료. 쥔 채 차단 시 손으로 받지 않는다 |
| 판정 실패 + 실제로 안 집힘 | `hover` 개방, 사람이 다시 적재. 진행 |
| **판정 실패인데 실제로 쥐고 있었음(거짓 실패)** | `hover`에서 블록이 떨어질 수 있다. 다음 적재 요청에 **적재하지 않는다**. 5분 뒤 시간 초과로 세션이 멈춘다. 판정값 재검토 |
| 판정 성공인데 보드에 블록이 있음(거짓 성공) | 사용자가 말한다. 빈 손 동작을 막기 위해 전원 차단, 세션 종료. 판정값 재검토 |
| 미완료 | 세션 중단, 기록. 같은 시도를 다시 하지 않고 조건을 정리해 새 승인 |

### 판정값 고정 규칙

- 교정 원본과 당시 판정을 보존한다. 조정한 값으로 이 세션의 시도를 다시 채점하지 않는다.
- 후보 값이 사람 관찰과 맞으면 그대로 고정한다. 안 맞으면 값 조정을 플랜으로 만들어 커밋하고, 필요하면 교정을 새 기록으로 다시 한다.
- **실패 표본이 없으면 「두 부류 분리 확인」으로 쓰지 않는다.** 그 경우 떠난 쪽 값만 확인한 것이고 남은 쪽은 `G0b-0`과 사전측정 사진뿐이라고 적는다.
- G0b 시작 전에 고정하고 이후 바꾸지 않는다. G0b 데이터로 임계값, ROI, 셀을 조정하지 않는다.
- ROI나 임계값은 표와 별개이므로 G0a를 다시 하지 않는다. 구성(표, 닫기)이 바뀌면 영향받는 게이트를 다시 한다.

### 열 기준

공식 사양이 없다. 40 ℃와 상승 15 ℃는 운영 한도이고 검증된 안전 한도가 아니며 보수성도 입증되지 않았다. 앞 플랜의 30초 타이머는 닫힘마다 유지한다. 누적 90초와 세션 사이 5분은 앞 시험 전용이고, 이 세션은 아래 기준으로 대체한다.

| 측정 | 방법 |
| --- | --- |
| 대상 | **그리퍼 서보 같은 면, 같은 거리**, 비접촉 온도계. 전원 차단 위치에서만 |
| 기록 | 실내 온도(작업대 표면), 서보 시작값, 팔이 `park`로 멈춘 때의 값, 시각 |
| 시점 | 시작 전, 끝. 5시도 근처는 손이 안 닿고 재기 쉬울 때만 |
| 초과 | 시작값 +15 ℃ 이상 또는 40 ℃ 이상을 **읽는 즉시 전원 차단.** 시도 경계 중단 경로가 없으므로 기다리지 않는다 |
| 측정 불가 | 끝값을 못 재면 열 확인 불인정 |

**열 확인 인정 조건 (모두 충족)**: 고정 10시도가 전부 끝남, 중단·안전 사건 없음, 끝값 측정 완료, 끝값이 기준 아래, 사람 재적재가 생긴 시도(판정 실패) 2건 이하. 재적재가 많으면 연속 운반과 부하가 달라 인정하지 않는다. **조기 종료나 미완료는 낮은 온도여도 열 확인 불인정이다.**

**G0b 적용**: 이 확인은 「10회 연속」까지만 말한다. G0b는 **시험표 30회를 시험 순서대로 10회씩 3묶음**으로 돈다. 묶음 사이 5분 이상 쉬고 같은 측정을 한다. 묶음 시작 온도가 첫 시작값 +5 ℃ 이내가 아니면 더 쉰다. 초과 처리는 위와 같다.

- **집계**: 세션 폴더를 `runs/G0b/` 하나로 두어 기록 파일(`replay-stored.jsonl`)과 쓰기 수를 공유한다. 묶음 파일은 원본 30회의 앞·중간·뒤 10개이고 `trial_id`, 순서, 구성, 판정값이 같다. **판정은 `summary --sheet results/G0b/sheet-config5-seed1.json --ledger runs/G0b/replay-stored.jsonl`, 즉 원본 30회 기준이다.** 묶음별 집계는 판정이 아니다.
- **중복·누락**: 기록의 `trial_id`로 중복을 막는다. 묶음 뒤 `summary`의 누락을 확인한다. 3묶음을 다 돌아야 `gate_pass=true`가 가능하다.
- **낙하**: 어느 묶음이든 낙하를 보면 런북 규칙대로 **30회 전체 미통과**다.
- **쓰기**: 전부 성공 시 단일 실행 312회, 3묶음 336회(경계마다 내려놓기 5회, 재적재 5회, 프로세스 시작 2회). G0b 승인 때 최악 경로를 Fake로 계산해 상한을 정한다.
- 묶음 나누기는 합격선과 시험표를 바꾸지 않는다. 시험 전에 커밋한다.
