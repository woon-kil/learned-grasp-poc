# H2-A 열린 손끝-작업대 간격 자 판독 (결과)

2026-11-11 KST. 플랜 `docs/*그리퍼-개폐별-손끝-돌출-측정-플랜.md` v2의 1단 A다. 승인: 「승인, 시작확인」(그리퍼 온도는 재지 않음). `dabai-view`(열린 손, `r_index 4`, J1 90, J5 90, 모델 TCP z 19.42 mm 자세), 쓰기 5회, 닫지 않음, 블록 없음. 승인 파일 `runs/H2-A/approval.json`(gitignore). 종료 후 관절 [90, 90, 90, 90, 89, 100]. 이동 중 관찰: 사용자 답변 대기. 사진 `data/h2/a/`(gitignore).

## 1. 방법 (사용자 변경 반영)

- 자를 미리 놓으면 팔 충돌 위험이 있다는 사용자 판단으로 **팔이 grasp에 자리 잡은 뒤 사용자가 손으로 자를 세워 댔다.** 팔은 신호 파일 전까지 움직이지 않았고, 사용자가 「손 뺐다」고 알리기 전에는 신호를 보내지 않았다. 대기 약 3분 30초(상한 300초 안).
- 구역은 시작 전 Gemini 사진으로 비어 있음을 확인했다(`data/h2/a/before.png`). 대기 중 Gemini 보조 사진(`grasp-ruler.png`)에서 자가 왼쪽 손끝 바깥에 세워져 있었다(손끝보다 약간 뒤라 시차 가능).

## 2. 판독값 (사용자, 자 눈금, 작업대 면 영점)

| 손끝 | 가장 낮은 끝의 작업대 위 높이 |
| --- | --- |
| 왼쪽 (L) | **22 mm** |
| 오른쪽 (R) | **20 mm** |

- 두 손끝의 차 2 mm는 판독 정밀도(±1~2 mm 추정) 안이거나 손끝 높이가 실제로 다른 것이다(구분 못 함).
- 예상값은 판독 전에 알리지 않았다.

## 3. 중간 비교 (B 전, 판단 보류)

- **열린 손끝은 모델 TCP z 19.42 mm와 같은 높이(20~22 mm)** 에 있다. 곧 이 자세에서 열린 손의 손끝이 TCP 높이와 거의 일치한다.
- 참고: G0b-3(`docs/261109-1622-…`, 구성 5, SDK 155, 같은 자세)에서 **닫은 손끝**을 사용자가 약 6.4 mm(추정)로 읽었다. 평균 열림 21 mm와 6.4 mm의 차 **약 14.6 mm**가 열림→닫힘 돌출 후보다. 그러나 ① 6.4 mm는 이전 세션·구성 5의 추정이고 독립 측정이 아니며(문서에 한계 명시) ② 이번과 같은 판독 방식으로 닫힘을 다시 읽지 않았다. **돌출 결론은 B(같은 방식으로 닫힘 읽기) 후에 낸다.**
- 이 후보값(약 14.6 mm)은 `HARDWARE-FACTS.md`의 16~20 mm 범위보다 약간 낮고, URDF 모델의 「간격 40→30 mm 구간 약 3 mm」와는 크게 다르다. 모델과 기록 어느 쪽이 맞는지는 B와 SDK 대응 확인 후 정한다.

## 4. 한계

- 사용자가 손으로 댄 자의 판독이며 한 번이다. 눈높이와 자의 앞뒤 위치로 시차가 생긴다.
- 좌우 손끝 높이 차(2 mm)의 원인을 구분하지 못했다.
