## 촬영


24단계, 32장이다. 출력은 `runs/judge-4`이고, 이미 있으면 거부한다.

| 단계 | 자리 | 사진 |
| --- | --- | --- |
| 1~5 | N: 베이스 판에 거의 닿게, 보드 마커 보임 | 놓기 3, 돌림 +1, 돌림 −1, 밀림 1, 치움 1 |
| 6~10 | P1: 베이스와 보드 마커 사이 가운데, 보드 마커 보임 | 같음 |
| 11~15 | M: 글자 쪽 끝이 보드 마커 바로 앞, 보드 마커 보임 | 같음 |
| 16~20 | P3: 보드 마커를 덮음(`y` 입력) | 같음 |
| 21~24 | E1~E4: 종이 가장자리(매번 `y` 입력) | 각 1 |

- **자리 확인:** 찍기 전 미리보기로 N·P1·M은 보드 마커가 보이는지, P3는 안 보이는지 확인한다. E는 바깥 기준 마커 id 0, 1이 보이는지 확인한다.
- **시작 전 중단:** 시작할 때 id 0, 1이 없으면 시험 사진 없이 끝낸다.
- **E4:** 새 자리다. 분홍 표시 반대쪽 종이 가장자리의 가운데쯤이며, 새로 넣은 왼쪽 띠 영역을 본다.

## 판정 (28건)

비교 기준은 각 자리의 `-base-00`이고, E는 `P1-base-00`이다.

| 비교 | 건수 | 합격 조건 |
| --- | --- | --- |
| 같은 자리(`base-01`, `base-02`) | 4자리 × 2 = 8 | 모두 실패 판정 |
| 돌림 +, 돌림 −, 밀림 | 4자리 × 3 = 12 | 모두 실패 판정 |
| 치움 | 4 | 모두 성공 판정 |
| E1~E4 | 4 | 모두 실패 판정 |

28건이 모두 맞아야 합격이다.

## 유효 조건

다음을 하나라도 어기면 무효다.

- 촬영 로그가 완결되고, 단계가 순서대로 모두 있어야 한다.
- 32장이 모두 있어야 한다.
- P3에서 `y`를 입력했어야 한다.
- E1~E4를 모두 `y`로 확인했어야 한다.
- 바깥 기준 마커 id 0, 1이 32장 모두에서 검출되고, 각 마커가 중앙값에서 2화소 이내여야 한다.

무효면 판정하지 않고 이 계약을 끝내며, 새 계약으로 간다. 다시 찍어 이 계약을 잇지 않는다.
