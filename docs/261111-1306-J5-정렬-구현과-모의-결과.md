## 2. 모의 (`scripts/j5_align_sim.py`, 모의이고 실측 아님)

```
창 m(ψ): ψ0 9.05, 3° 7.50, 5° 6.48, 8° 5.00, 10° 4.04, 14° 2.20 mm. 횡방향 σ 2.13 mm
손 yaw 모델 오차 σ 2.5°: J5 90 정렬 없음 성공 0.995, 정렬 후 0.999
손 yaw 모델 오차 σ 3.9°: J5 90 정렬 없음 성공 0.985, 정렬 후 0.995
손 yaw 모델 오차 σ 5.5°: J5 90 정렬 없음 성공 0.962, 정렬 후 0.979
(J5 90, 정렬 없음에서 반경선 기준 |d|>5° 비율 0.28: 목록 40자리 평균)
놓기 J5(목록 40자리): 최소 82, 최대 93, J5≠90 자리 36개
```

읽기:
- 횡방향 창은 ψ 5° 6.48 mm, 10° 4.04 mm다. L1+L2 횡방향 σ 2.13 mm 대비 손과 블록의 어긋남이 5~8° 수준이면 성공 확률은 이미 0.985~0.995다. 즉 **집기 성공 확률은 정렬 없음에서도 높게 모의되고, 정렬 후 0.995~0.999**다. 정렬의 이득은 확률의 작은 증가가 아니라 **방향 분포의 평균을 0으로 두어 ψ가 허용 문턱(5°)을 넘는 일(자동 정지)을 줄이는 것**이다.
- 정렬 없음에서 반경선 기준 |d|>5° 비율은 약 0.35(목록 평균, 모델 + 셀 안 2.5°)다. 정렬 뒤에는 방향 기준이 손 yaw 예측이라 이 정지가 사라진다. 다만 새 기준의 psi_deg는 모델 자체의 값이라 **실제 어긋남을 재지 못한다**(모델 오차가 포즈 단위 LOO 3.9° 상한). 실제 효과는 실기에서 집기 전·놓은 뒤 사진으로 재야 한다.
- 놓기 J5(40자리): 82~93, J5≠90 36개. 놓을 때 보정량이 작아 다음 집기 J5 보정도 작아질 것으로 본다.
- 한계: 모의의 모델 오차 σ(2.5, 3.9°)와 측정 오차(1.5°)는 가정이다. 손 yaw 모델은 J5 90 포즈 4개에 기대고 J5 60·90·120 세 수준뿐이다. 모든 실기 성공은 J5 90이었다.

### 2.1 모의의 한계와 advisor 지적 반영

- **횡방향만 모의했다.** 반경 오차(σ 약 4 mm)의 허용은 측정한 적이 없다.
- **정렬 후 방향 게이트는 실질적으로 없다.** `plan_aligned`의 `psi_deg`는 모델 자신의 J5 해에 대한 잔여라 J5 반올림 수준(약 2° 이하)에 머문다. 남은 방향 거절은 J5 범위 초과뿐이다. 실제 손-블록 어긋남은 **측정되지 않는다.** 표본 밖 자료(연쇄 4개 읽기)의 손 yaw 모델 잔차가 5~7°로 모의 σ(2.5, 3.9°)보다 커서 σ 5.5° 행을 추가했다: 그 경우에도 모의 성공은 높지만(위 출력), 이는 횡방향 창만 본 값이다. 사용자 결정(하강 확인 면제는 ψ ≤ 5°로 제한된 시도 전제였음)이 정렬 후에도 유지되는지는 요청에서 묻는다.

### 2.2 이월(carry-over) 확인 (쓰기 0, `scripts/j5_carryover.py`)

집을 때 어긋남 δ_pick(집기 전 블록 d − 손 yaw 모델)이 놓인 뒤 잔차 ρ_place(놓인 뒤 d − 손 yaw 모델)로 이어지는지, 연쇄 4개 전이로 본다.

```
{carry}
```

- δ_pick이 작을 때(C, −1.7°)보다 클 때(A, B, D, −6.8~−7.7°)의 ρ_place와 **양의 상관**이 보인다. 같은 자리 (8, 104)에 놓은 A와 C는 δ_pick이 6° 다르고 ρ_place가 약 12° 다르다. 턱이 블록을 손 방향으로 완전히 돌려 쥔다면 ρ_place는 δ_pick과 무관해야 하므로, **쥔 각도가 어느 정도 보존된다는 가설(사용자 의견)과 방향이 맞는다.**
- 그러나 **표본 4개**이고 δ_pick의 모델 항(손 yaw 모델 오차 최대 약 4°)이 섞여 있어 결론이 아니다. 기울기가 약 2로 1보다 큰 것도 설명되지 않는다. 가설로 두고 sanity 실행에서 집기 정렬 유무로 직접 잰다(아래 기록 항목).

### 2.3 실행기 변경(같은 지적)

- 실행이 정상 종료하면 **마지막으로 놓은 블록의 사진을 한 번 더 찍는다**(쓰기 없음, `chain-NNN`). 마지막 놓기의 방향도 측정되게 한다.
- sanity와 본 실행이 시도마다 남길 기록: 집기 전 d(`plan.d_deg`), 집기 J5(`pick_j5`), 놓기 J5(`place_j5`), 놓인 뒤 d(다음 시도의 `plan.d_deg`, 마지막은 마지막 사진). 놓인 뒤 d의 예측은 약 0(놓기 정렬이 맞으면).
- 본 실행(40시도)의 판정은 36/40 그대로이고, **놓인 뒤 d 분포와 자동 정지 횟수를 함께 보고**한다. 실기 J5는 약 80~100만 쓰인다. J5 극단과 범위 거절 경로는 Fake 시험으로만 확인했다.
