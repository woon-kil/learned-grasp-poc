## 4. 결론

- **유효.** P1 보드 마커 10/10, P3 0/10, P3 사람 확인 y, 사진 확인 yes.
- **측정 합격.** 윗면 마커 검출·돌림 구분·위치 이동·기준 마커(최대 0.354 px)가 모두 기준 안이다.
- **판정 불합격.** P1에서 블록을 치운 사진이 변화 0.0182로 문턱 0.02 미만이라 거짓 실패다. 노란 화소는 0이었다.
- 계약대로 G0d에 들어가지 않는다. 판정값(변화 0.02, 노란 화소 100, PICK_ROI)을 플랜에서 다시 정하고, 판정 부분만 새 계약과 새 사진으로 본다. 측정 합격은 유지한다. 기준 수치는 이 결과에 맞춰 바꾸지 않는다.
- 관찰(원인 확정 아님): P1 제거 변화 0.0182는 P1 돌림 사진 변화(0.018~0.025)와 같은 크기다. 변화량만으로는 P1에서 「치움」과 「돌림」이 갈리지 않고, 이번에 둘을 가른 것은 노란 화소였다.
