# DB-8-4 블록을 DB-7 자리로 되돌린 재현 시험 (결과)

2026-11-10 KST. 목적: DB-8-1·2에서 DB-7 대비 좌우 이동과 무관하게 같은 부호로 나온 마커 행 변화(약 −10 화소)의 원인 확인. 승인: 「승인, 시작확인」(그리퍼 온도는 재지 않음). 쓰기 3회(`dabai-view --r-index 0 --hover-only`), 닫지 않음, `grasp` 없음. 승인 파일 `runs/DB-8-4/approval.json`(gitignore). 종료 후 J2 91. 이동 관찰: 사용자 답변 대기. 배치 안내 `data/db8/db8-4-guide-photo.svg`.

## 1. 배치 확인 (Gemini)

블록을 DB-7 자리로 되돌렸다. Gemini 사진에서 블록 노란 영역은 DB-7 대비 열 +2, 행 +2 화소(약 1.6 mm)였고, 방향은 같고 마커는 가려지지 않았다.

## 2. 측정값 (고정 절차, 한 번)

| 항목 | DB-7 | DB-8-4 | 변화 |
| --- | --- | --- | --- |
| 블록 마커 id 7 중심 (열, 행) | (378.0, 411.8) | (372.0, 405.8) | **Δ열 −6.0, Δ행 −6.0** |
| id 7 변 길이 / 각도 | 94.8 / −177.6° | 94.3 / −177.6° | −0.5 / 0 |
| 보드 마커 id 1 중심 | (363.0, 256.8) | (362.8, 256.8) | 0.2, 0 |

## 3. 해석: 행 변화의 원인은 블록이 밀린 것이다

고정 Gemini 사진에서 블록 노란 영역 중심의 DB-7 대비 변화와 DaBai 마커 중심의 DB-7 대비 변화를 함께 놓았다(Gemini는 1.24 화소/mm, 위쪽 = 베이스).

| 회차 | Gemini Δ열, Δ행(화소) | Gemini 환산(mm) | DaBai Δ열, Δ행(화소) | 모델 스케일(좌우 3.75, 앞뒤 4.03)로 예측한 DaBai |
| --- | --- | --- | --- | --- |
| DB-8-1 | +15.0, +3.0 | 12.1 우, 2.4 사용자 쪽 | −43.2, −10.8 | −45.4, −9.7 |
| DB-8-2 | −12.0, +2.0 | 9.7 좌, 1.6 사용자 쪽 | +37.5, −8.8 | +36.3, −6.5 |
| DB-8-4 | +2.0, +2.0 | 1.6 우, 1.6 사용자 쪽 | −6.0, −6.0 | −6.0, −6.5 |

- **세 회차 모두 Gemini가 본 블록 이동(열·행)과 DaBai 마커 이동이 모델 스케일로 서로 맞는다**(차이 최대 약 2.5 화소). 두 카메라가 독립적으로 같은 이동을 본 것이다.
- 따라서 **DB-7 이후 공통 행 변화(−10 화소)는 블록이 놓이거나 밀릴 때 사용자 쪽으로 약 1.6~2.4 mm 밀린 결과**로 설명된다. 카메라·팔 자세 변화가 아니다(보드 마커 id 1은 네 회차 모두 0.6 화소 안).
- DB-8-1, 2에서 환산한 이동량은 Gemini 기준 12.1 mm(우)와 9.7 mm(좌)다. 사용자 값 10 mm, 모델 환산 11.5 mm·10.0 mm와 함께 보면 오른쪽 이동은 10~12 mm, 왼쪽은 약 10 mm다.
- **사람이 손으로 블록을 다시 놓는 반복 정밀도**는 이번에 열 +1.6 mm, 행 +1.6 mm였다. 이 값이 시험에서 별도의 오차 요인이다.

## 4. 한계

- Gemini 화소 하나는 약 0.8 mm라서 위 환산은 ±1 화소(±0.8 mm) 불확실하다.
- 재현은 한 번이다. 같은 자리 반복 hover의 순수 반복성(블록을 건드리지 않고 두 번 찍기)은 이번에 따로 재지 않았다(보드 마커 id 1은 매 회 0.6 화소 안).
- 높이 값은 법선 모호성으로 신뢰하지 않는다.
