# L1 맵 J5 선형성 점검 결과 (쓰기 0)

작성: 2026-11-11 KST. 사용자 질문(손목 수평 각도가 손끝과 물체 간격에 미치는 영향이 고려됐나)과 제안(J5 중간값에서 맵 점 추가로 선형 가정 점검)에 대한 쓰기 없는 점검. 새 실기 없이 기존 연쇄 장부(CH-3, X1-0, X1-1)의 **팔이 놓은 블록**을 표본 밖 자료로 썼다.

## 1. 점검 방법

L1 맵은 G0b·G0c 20점(J5 60·90·120)으로 맞춘 2차 다항식 + J5 선형 항이다(`config/l1_map.json`). 연쇄에서 팔이 (손 행, 공칭 J1, 놓기 J5)로 놓은 블록의 영상 위치(다음 시도의 `plan.du/dv`)를 맵의 순방향 예측과 비교했다(`scripts/map_j5_check.py`). 오프셋(R1·X2)·사람 재배치 시도는 뺐다.

## 2. 결과 (`scripts/map_j5_check.py` 출력)

```
놓인 블록 62개(오프셋 없음, 성공, 사람 재배치 제외)
  J5 [55,72): n 7, 횡방향 잔차 평균 +2.5 mm (표준편차 0.9), 반경 잔차 평균 -2.4 mm (표준편차 1.1)
  J5 [72,86): n 8, 횡방향 잔차 평균 +1.5 mm (표준편차 0.9), 반경 잔차 평균 -1.3 mm (표준편차 1.5)
  J5 [86,96): n 41, 횡방향 잔차 평균 +0.8 mm (표준편차 1.1), 반경 잔차 평균 +1.4 mm (표준편차 2.4)
  J5 [111,125): n 6, 횡방향 잔차 평균 +1.2 mm (표준편차 1.5), 반경 잔차 평균 +2.8 mm (표준편차 1.1)
횡방향 잔차 ≈ +1.09 mm -0.028 mm/J5°, 반경 잔차 ≈ +1.01 mm +0.121 mm/J5° (J5 편차 ±30°에서 횡방향 ±0.8 mm, 반경 ±3.6 mm)
횡방향 2차 항 +0.0019 mm/J5°² (J5 ±30°에서 1.8 mm)
```

- **횡방향**: J5 구간별 잔차 평균이 +2.5(J5 55~72), +1.5(72~86), +0.8(86~96), +1.2 mm(111~125)로 **J5 편차 ±30°에서의 변화는 선형 ±0.8 mm, 2차 포함 ±1.8 mm**다. 맵의 J5 선형 가정은 횡방향(창 약 6.5~9 mm, L1 횡방향 σ 약 2.1 mm)에 비해 작은 오차다. 구간 내 표준편차 0.9~1.5 mm는 L1 측정 잡음 수준이다.
- **반경**: 잔차가 J5에 따라 −2.4(낮은 쪽) → +1.4(90 부근) → +2.8 mm(높은 쪽)로 **기울기 +0.12 mm/J5°**, ±30°에서 ±3.6 mm다. 반경 허용(≥ 약 ±15~17 mm, R1)에 비해 작다.
- **일정한 치우침**: J5 90 부근에서도 횡방향 +0.8 mm, 반경 +1.4 mm의 일관된 잔차가 있다(R1에서 본 놓인 블록 반경이 공칭보다 평균 +1~3 mm 바깥인 원인 후보로 보인다. 맵 편향 쪽이 유력하나 쥠 이동의 가능성은 따로 가르지 못했다).
- **J5 96~111 구간은 표본이 없다**(연쇄 일정이 정렬 놓기 J5 82~93과 극단 64~68·112~116이었다). 선형성의 직접 점검은 이 구간 데이터가 있어야 완결된다.

## 3. 맵을 연쇄 점으로 다시 맞추면?

연쇄 놓인 블록 점을 훈련에 더해 다시 맞춘 맵을 **보류한 세션**에서 평가했다(표본 밖):

```
보류 X1-1(n 22): 기존 맵 du 2.27 dv 3.47 2D 4.14 화소 → 연쇄 점 추가 맵 du 1.95 dv 3.05 2D 3.62 화소
보류 CH-3(n 37): 기존 맵 du 2.05 dv 2.58 2D 3.29 화소 → 연쇄 점 추가 맵 du 1.80 dv 2.37 2D 2.98 화소
```

2D 오차가 약 10~12%(0.3~0.5 화소, 약 0.3~0.5 mm) 줄 뿐이다. **지금 맵을 바꾸지 않는다**: 개선이 작고, 바꾸면 P1·CH·R1·X의 비교 기준이 달라진다. 향후 L3(폐루프)나 정밀도 향상이 필요해질 때 이 점들로 맵 v2를 만들 수 있다(`config/l1_map_v2.json`로 별도 파일).

## 4. 결론

손목 각도(J5)의 효과는 세 층으로 반영돼 있다: 방향 어긋남 창(ψ), 손끝 위치 이동(맵 J5 항, 점검 결과 선형 가정 오차 횡방향 ≤ 약 1.8 mm, 반경 ≤ 약 3.6 mm), 손 yaw 모델(J5 정렬). J5 중간값(96~111)의 직접 점검은 데이터가 없어 미완이다. 다음 연쇄 실행에서 놓기 J5에 그 구간을 넣으면 쓰기 비용 없이 채울 수 있다.
