# P1 정렬 안내가 맴돈 이슈 보고서

작성: 2026-11-11 KST. 관련: `docs/261111-1128-P1-조기-마감-결과.md`.

## 현상

P1에서 블록 방향(ψ ≤ 5°) 정렬에 대화 왕복이 반복됐다. p1-10은 5번, p1-16은 4번, p1-15·17은 3번 놓았다. 사용자가 「계속 측정 좌표가 맴도는 것 같다」고 지적했다. 이어서 p1-15에서는 돌릴 방향을 거꾸로 안내해 ψ가 5.3°에서 12.4°로 벌어졌다. p1-16은 81°에서 65°로 지나치게 돌았다가(ψ 9.2°) 78°(6.0°)를 거쳐 74°에서 통과했다.

## 원인

1. 각도를 「도」로 안내했다. 손으로 5°는 가늠하기 어렵고 한 번에 맞추기 힘들다.
2. 통과 조건이 아닌 위치까지 목표에 맞추라고 같이 요구했다. 위치는 L1이 놓인 자리를 그대로 측정하므로 구역 안이면 충분했다.
3. 회전 방향을 사진 방향(블록이 수직에서 오른쪽/왼쪽으로 기운 정도)에서 직접 유도하지 않고 기억에 의존했다. 각도가 90°를 넘는 자리(J1 < 90)와 아래인 자리의 부호 관계를 한 번 거꾸로 썼다.
4. 사전 규칙(다시 놓기 최대 2회)을 어기고 p1-10, p1-16을 계속 조정했다.

## 수정

- 이후 안내는 중심을 두고 **블록 끝을 몇 mm 옮길지**로 말했다(5°≈2.6 mm). p1-17은 2회 조정으로 통과했다.
- 회전 방향은 이동할 끝을 사진 기준 좌우로 명시하고 각도가 커지는 쪽을 함께 적었다.
- 구조적 해결은 사람 정렬을 빼는 것이다: `docs/261111-1129-사람개입-최소화-측정-정책-플랜.md`.

## 교훈

- 사람이 손으로 맞추는 양은 도가 아니라 mm로 안내한다. 방향은 이동할 끝을 기준으로 쓴다.
- 통과 조건이 아닌 값은 사용자에게 맞추라고 하지 않는다.
- 사전 규칙(재배치 상한)을 어기게 되면 그 자리에서 규칙대로 새 자리로 바꾼다.
- 시도 수에 비례해 사람 노력이 드는 설계는 반복 측정에 맞지 않는다. 새 측정 계획은 시도당 사람 접점을 먼저 센다.
