# X1 J5 극단 연쇄 검증 플랜 (v2, 승인 요청)

작성: 2026-11-11 KST, v2는 같은 날(advisor 지적 반영). 사용자 지시 「푸시하고 다음 작업 진행」(작업 현황 문서의 다음 작업 우선순위 2: J5 극단 검증). **승인 전이다. 팔에 명령을 보내지 않았고 코드도 바꾸지 않았다.** 앞선 결과: `docs/*P2-사람-배치-J5-정렬-결과.md`(실제 극단 J5 3개, 최대 편차 29°), `docs/*CH-3-J5-정렬-연쇄-40시도-결과.md`(J5 78~98), `docs/*J5-블록-방향-정렬-분석과-계획.md`.

## 1. 질문과 설계 요지

**쓰기 없는 사전 확인(advisor 지적)**: 손 yaw 모델은 J5 60·90·120의 70장(20 포즈)으로 맞췄다. 포즈 단위 leave-one-pose-out 잔차를 J5 그룹별로 다시 냈다(`runs/G0b/j5-yaw.json`):

```
J5 60: 포즈 10개, 사진 30, LOPO 잔차 평균 +0.1°, 표준편차 3.9°, |최대| 9.8°   (셀 평균 잔차 표준편차 3.0°)
J5 90: 포즈 4개, 사진 14, LOPO 잔차 평균 +2.5°, 표준편차 4.2°, |최대| 9.3°   (셀 평균 4.0°)
J5 120: 포즈 6개, 사진 26, LOPO 잔차 평균 -0.5°, 표준편차 3.4°, |최대| 9.3°  (셀 평균 3.1°)
```

즉 **훈련 극단(J5 60·120) 자체의 모델 오차는 이미 약 3~4°**다. 모델 정확도는 훈련 범위 안에서는 대체로 답이 나와 있다. **X1이 새로 주는 것은 (a) 실기에서 편차 20~30°로 집은 성공률(P2는 3개뿐)과 (b) 훈련 극단 사이(J5 64~68, 112~116, J1·행이 훈련 포즈와 다른 곳)의 놓은 뒤 방향 잔차**다.

**질문**: 극단 J5(편차 약 20~30°)로 집는 것이 24시도 안에서 안정적으로 성공하는가, 극단 놓기 J5의 방향 예측이 맞는가.

**설계(사람 개입 최소)**: 연쇄 시험에서 **놓는 J5를 극단과 정렬 J5(`yaw.place_j5`, 방향 d ≈ 0)로 번갈아 정한다.** 중간 거절 뒤 사람이 다시 놓은 시도는 `human_placed`로 표시해 극단 집기 성공·커버리지 집계에서도 제외한다.
- 홀수 시도(3, 5, …)는 직전에 정렬 놓기로 놓인 블록(d ≈ 0)을 near-90 J5로 집고 **극단 J5로 놓는다**(놓기 J5 일정 {64, 66, 68, 112, 114, 116}, 각 2번). 이 놓기 뒤 d의 실측−예측 `hand_d(놓기 J5, J1, 행)`이 극단 모델 오차의 근사다(앞 집기의 쥠 어긋남과 놓는 순간 흔들림이 섞여 있으나 CH-3 정렬 놓기 값(3.4°)과 같은 성분이라 그 기준선과 비교한다).
- 짝수 시도는 그 극단으로 돌아 놓인 블록을 L1이 정하는 **극단 J5로 집고**(편차 약 20~30°) 정렬 J5로 놓는다. 이것이 **극단 집기 성공 시험**이다. 이 뒤 정렬 놓기의 d 잔차는 「극단 집기 뒤」 값으로 따로 보고한다(이월 효과).
- 사람은 시작 적재뿐이다. 놓는 자리는 행 3~6(`config/x1_schedule.json`).
- **J5 범위 끝 규칙(사전 고정)**: 보정 J5가 범위(60~120) 밖이어도 **4° 이하**로 벗어나면 60 또는 120으로 자르고 `clamped`를 기록한다. 4°를 넘으면 거절한다. CH-3·P2의 「자르지 않고 거절」의 극단 한정 이탈이다.
- **중간 거절 처리(사전 고정)**: L1 거절(클램프 4° 초과, 구역 밖)이 나면 시도로 세지 않고 멈춘다. 사람이 블록을 다시 놓으면 같은 시도 번호·같은 자리로 이어 가며, 다시 놓은 블록의 방향은 사람 배치로 표시하고 **모델 정확도 지표에서 제외**한다(팔이 만든 극단 방향이 사라지므로).
- 실제 사용 J5 편차: 놓기 편차 22~26°, 집기는 노이즈를 더해 약 20~30°다. **편차 ≥ 26은 노이즈로만 기대**하고 J5 60·120 끝을 체계적으로 덮는다고 주장하지 않는다.

## 2. 측정(사전 고정)

| 지표 | 정의 | 판정 |
| --- | --- | --- |
| 전체 집기 성공 | 관찰기 그리고 서보 6 판독 ≤ 151 | 24시도 ≥ 22/24 |
| **극단 집기 성공** | 짝수 시도(극단 J5로 집은 12개) | ≥ 11/12 |
| **극단 놓기 모델 오차** | 홀수 시도(near-90 집기 뒤)의 놓인 뒤 d 실측 − 예측, n 약 11. 이 값에는 앞 집기의 쥠 어긋남과 놓는 순간 흔들림이 들어 있다(carry-over 없는 값이 아님). 기준선은 CH-3 정렬 놓기 표준편차 3.4°이고 **3.4°를 넘는 만큼을 극단 모델 오차로 읽는다** | 표준편차 ≤ 5.0° |
| 극단 집기 뒤 이월 | 짝수 시도 뒤 정렬 놓기의 d 잔차 | 홀수 값과 따로 보고(이월 효과) |
| 실제 극단 J5 | 짝수 시도의 실제 \|J5−90\| ≥ 20인 시도 수, ≥ 26인 수 | ≥ 8개, ≥ 3개(노이즈 의존) |
| 클램프 | 자른 시도 수와 크기 | 보고 |

모델 오차가 5°를 넘으면 그 크기를 한계로 보고한다(실패가 아니라 한계 보고).

## 3. 구현 (승인 후)

1. `l1.plan_aligned`에 `j5_clamp_margin`(기본 0)을 추가해 범위 끝 4° 이내 자르기와 `clamped` 기록. Fake 시험.
2. `run_chain`: `place_j5_schedule`, `--x1 config/x1_schedule.json`. 놓는 손 행·J5는 일정 값. Fake 시험.
3. `scripts/x1_schedule.py`: 24시도 일정(시드), 행 3~6 놓을 자리, 홀수 시도 극단 놓기 J5 일정 {64, 66, 68, 112, 114, 116}(각 2번), 짝수 시도는 정렬 놓기.
4. `scripts/x1_summary.py`: 지표(성공, 모델 오차, 사용 J5 분포, 클램프).
5. 1단 sanity **4시도**(`config/x1_sanity.json`: 놓기 J5 [112, 정렬, 64, 정렬], 새 폴더 `runs/X1-0`): 높은 쪽·낮은 쪽 극단 놓기와 극단 집기를 각 방향 한 번씩. 쓰기 약 41, `max_writes` 50.

## 4. 안전·확인

- 하강 확인(**방향별**): 이 실행의 첫 집기, 그리고 J5>90 쪽·J5<90 쪽 각각에서 편차 15° 이상을 **처음** 쓰는 집기·놓기, 그 방향 이전 확인 최대보다 10° 이상 커질 때. 즉 높은 쪽 첫 극단 놓기, 낮은 쪽 첫 극단 놓기에서 확인이 오고 같은 쪽 두 번째 극단은 없다(Fake 시험으로 확인). 그 뒤는 전원 차단 감독. 프로세스마다 카운터가 초기화된다. 정지 파일, 쉼(닫기 10번마다 10분).
- 빈 손 실패는 hover에서 열고 park(grasp 재하강 없음)하고 **이어 가지 않는다**(X1에서는 연속 실패로 블록이 어긋날 수 있어 사람이 확인한다. R1과 달리 continue-on-miss를 켜지 않는다).
- **J5 극단 자세의 실기 이력과 한계**: 구성 `j5_deg: [60, 120]`은 범위 한계이고 G0a 드라이런(`g0_runner.dryrun_sheet`)은 표 10행 × J1 {70, 90, 110} × J5 {60, 120}(빈 그리퍼)을 돌렸다. G0b·G0c는 같은 J1에서 J5 60·90·120 셀로 집었다. P2는 J5 67~119를 J1 73~104, 행 0~8에서 썼다(예: J5 119·J1 104·행 3, J5 67·J1 73·행 0). 그러나 **X1이 쓸 행 3~6 × J1 72~108 × J5 64~68·112~116 조합 전체가 실기로 확인된 것은 아니다.** 그래서 새 극단에는 확인을 유지한다: 첫 집기, |J5−90| 이전 확인 최대 +10° 상승 때마다, 처음 극단 놓기.
- 쓰기: 24시도 약 241회(상한 260). 소요 약 35분(쉼 2번 20분 포함). **그리퍼 휴식**: 오늘 닫기가 많았으므로 sanity 전에 30분 이상 쉬고 사용자 go-ahead를 받는다.

## 구현 후 보강 (advisor 2차 지적)

- **sanity는 전용 4시도 일정**이다(위 3절 5번). 낮은 쪽(J5 64~68) 극단이 본 실행에서 처음 무감독으로 돌지 않게 한다.
- **확인 상승을 방향별로** 바꿨다(위 4절). 대칭 규칙은 높은 쪽 확인 뒤 낮은 쪽 첫 극단을 확인 없이 내려보냈다.
- `clamped`는 반올림해도 범위 밖일 때만 켠다. `x1_summary`는 사람이 다시 놓은 블록을 극단 집기·커버리지에서 제외한다.
- 승인 요청 전에 종이띠 확인 사진과 현재 블록의 `plan_aligned(clamp 4°)` 결과를 낸다. 그리퍼 30분 휴식과 사용자 go-ahead가 필요하다. `--rest-sec 600`을 명시한다.

## 검토 이력

v1을 advisor가 검토해 ① 사전 쓰기 0 확인(훈련 극단 LOPO 3~4°로 모델 정확도 질문의 상당 부분이 이미 답이 있음) ② 올 극단 일정의 오차 혼합(이월)과 번갈아 극단·정렬 놓기 설계 ③ 안전 문구의 과장(극단 조합 실기 이력) ④ 중간 거절 처리 ⑤ 커버리지 주장 완화 ⑥ 승인 패키지(휴식, 이탈 명시)를 지적했고 v2에 반영했다. v2 구현 뒤 advisor 2차 검토가 sanity 일정, 방향별 확인, 문구, 집계의 문제를 지적해 위 「구현 후 보강」에 반영했다. 검토는 교차 모델이 아니다(같은 계열).
