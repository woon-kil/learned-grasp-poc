# X1 J5 극단 연쇄 검증 플랜 (초안, 승인 요청)

작성: 2026-11-11 KST. 사용자 지시 「푸시하고 다음 작업 진행」(작업 현황 문서의 다음 작업 우선순위 2: J5 극단 검증). **승인 전이다. 팔에 명령을 보내지 않았고 코드도 바꾸지 않았다.** 앞선 결과: `docs/*P2-사람-배치-J5-정렬-결과.md`(실제 극단 J5 3개, 최대 편차 29°), `docs/*CH-3-J5-정렬-연쇄-40시도-결과.md`(J5 78~98), `docs/*J5-블록-방향-정렬-분석과-계획.md`.

## 1. 질문과 설계 요지

**질문**: J5 정렬(손 yaw 모델)이 **J5 60·120 끝 쪽(편차 25~30°)** 에서도 맞는가. P2는 사람이 극단 방향으로 놓아 주지 못해 실제 극단이 3개뿐이었다(최대 29°).

**설계(사람 개입 최소)**: 연쇄 시험에서 **놓는 J5를 극단 값으로 일부러 정한다.** 팔이 극단 J5로 놓은 블록은 그 손 방향대로 반경선에서 약 ±30° 돌아 놓이고, 다음 시도가 그 블록을 L1(`plan_aligned`)이 정하는 극단 J5로 집는다. 사람은 시작 적재뿐이다. 블록 방향이 사람 손이 아니라 팔에서 나오므로 「극단으로 돌려 놓아 주세요」가 필요 없다.

- 놓기 J5 일정: {64, 66, 68, 112, 114, 116}에서 24시도(각 4번)를 시드로 섞는다(편차 22~26°). 놓는 자리는 행 3~6(R1과 같은 방식, `config/x1_schedule.json`). 집기 J5는 L1이 정한다(예상 편차 약 20~30°).
- **J5 범위 끝 규칙(사전 고정)**: 보정 J5가 범위(60~120) 밖이어도 **4° 이하**로 벗어나면 60 또는 120으로 자르고 `clamped`를 기록한다(잔여 어긋남 ≤ 4°는 모델 오차 크기와 같다). 4°를 넘으면 지금처럼 거절한다. 이는 CH-3·P2의 「자르지 않고 거절」의 극단 한정 이탈이다.
- **재배치 없음**: 거절이 나면 사람이 필요하다(연쇄는 거절 시 멈춘다).

## 2. 측정(사전 고정)

| 지표 | 정의 | 판정 |
| --- | --- | --- |
| 집기 성공 | 관찰기 그리고 서보 6 판독 ≤ 151(CH-3과 같음) | 24시도 ≥ 22/24 (≥ 0.92) |
| 손 yaw 모델 정확도(극단) | **놓인 뒤 블록 방향 d의 실측 − 모델 예측 `hand_d(놓기 J5, J1, 행)`**. 극단 J5의 모델 오차를 직접 잰다 | 표준편차 ≤ 5.0°(J5 90 근처 놓기 정렬에서 3.4°) |
| 사용 J5 | 실제 집기 J5와 편차 | 실제 \|J5−90\| ≥ 20 시도 ≥ 16개, ≥ 26인 시도 ≥ 4개 |
| 클램프 | 자른 시도 수와 크기 | 보고 |

판정 문턱을 넘지 못하면(모델 오차 > 5°) 그 크기를 보고하고 극단에서 J5 정렬 모델의 한계로 기록한다(실패가 아니라 한계 보고).

## 3. 구현 (승인 후)

1. `l1.plan_aligned`에 `j5_clamp_margin`(기본 0)을 추가해 범위 끝 4° 이내 자르기와 `clamped` 기록. Fake 시험.
2. `run_chain`: `place_j5_schedule`, `--x1 config/x1_schedule.json`. 놓는 손 행·J5는 일정 값. Fake 시험.
3. `scripts/x1_schedule.py`: 24시도 일정(시드), 행 3~6 놓을 자리, 놓기 J5 일정.
4. `scripts/x1_summary.py`: 지표(성공, 모델 오차, 사용 J5 분포, 클램프).
5. 1단 sanity(3시도: 놓기 J5 64, 116, 68): 쓰기 약 31, 확인 약 3번(첫 집기, 편차 상승).

## 4. 안전·확인

- 하강 확인: 첫 집기 + |J5−90|가 이전 확인 최대보다 10° 이상 커질 때(약 10, 20, 30° 부근, 총 3~4번). 그 뒤는 전원 차단 감독. 정지 파일, 쉼(닫기 10번마다 10분).
- 빈 손 실패는 hover에서 열고 park(grasp 재하강 없음)하고 **이어 가지 않는다**(X1에서는 연속 실패로 블록이 어긋날 수 있어 사람이 확인한다. R1과 달리 continue-on-miss를 켜지 않는다).
- J5 60·120은 G0b·G0c에서 실기로 쓴 적이 있고 구성 `j5_deg: [60, 120]`로 확정돼 있다. 극단 자세의 조합(J1·r)은 표 안이다.
- 쓰기: 24시도 약 241회(상한 260). 소요 약 35분(쉼 2번 20분 포함).

## 5. 하지 않는 것

판정 문턱·규칙 변경(1절 클램프 한정 이탈 제외), 사람 배치, 횡방향 오프셋, 관찰기 영역 변경.

## 6. 위험

| 위험 | 대응 |
| --- | --- |
| 극단에서 손 yaw 모델이 틀려 손이 블록과 어긋남 | 놓은 뒤 d의 모델 오차를 직접 측정, 집기 성공과 함께 보고. 첫 확인은 눈으로 |
| 블록이 극단 J5에서 크게 돌아 구역·관찰기 영역 밖 | 행 3~6 자리, L1 거절 시 멈춤 |
| 연속 실패로 블록이 어긋남 | continue-on-miss 끔, 실패 즉시 멈춤 |
| 그리퍼 과열 | 쉼 10분, 사용자가 알려 오면 정지 파일 |
