## 4. 읽기

- **손가락은 사진에서 분명히 보인다**(검은 원통 두 개, 14장 몽타주 확인). 문제는 사진이 아니라 **검출 알고리즘**이다. 손가락이 손 몸통의 링크와 같은 어두운 색으로 이어지고, 회전하면 손가락 한쪽이 다른 쪽보다 낮게 보이며 그림자·반사가 섞인다. 단순한 어두운 화소 기반 정의 4개가 모두 J5 변화에 안정적으로 반응하지 않는다.
- 정의 D(원통 추적)는 민감도 0.76으로 가장 가깝지만 검출이 7/14뿐이다(회전한 자세에서 사슬이 끊김).
- J1 민감도는 정의 A·C에서 음수(−0.38, −0.47)로 기대(약 +1.0)와 부호까지 다르다. 이 데이터로 J1 보정 진단은 불가능하다.

## 5. 결론과 다음

**Gemini hover 사진에서 단순 화소 기반으로는 손 방향을 믿을 수 있게 못 잰다**(이 구현들 기준). 가능한 다음 단계:
1. **손가락 끝점의 고유 특징 검출 재구현**: 템플릿 매칭(손가락 원통 윗부분의 흰 점·볼트 등 고정 특징), 깊이(`depth.png`)로 가장 낮은 3D 점, 또는 학습 없는 키포인트(예: 손가락 끝 원의 중심). 이미 확보한 28장 + 스윕 사진으로 쓰기 없이 반복 개선할 수 있다. 목표는 J5 민감도 0.9~1.1, 재방문 σ ≤ 0.3°.
2. 그래도 안 되면 손목 DaBai 카메라(L3 경로)로 손 좌표계에서 블록을 직접 본다.
3. X3·B(±2°)는 위가 성립하기 전까지 보류 유지.
