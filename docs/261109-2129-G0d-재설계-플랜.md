## 목표

G1이 쓸 **명령 공간 허용치**를 작은 범위부터 얻는다. 뜻: 블록을 명령 `P`로 놓은 뒤 `P+δ`로 집어도 집히는가. 정본 라벨 정의(「검증된 파지 명령 좌표」, 30행)와 같은 공간이다. **물리적 허용 오차가 아니다.** 물체에 대한 실제 상대 오차로 해석하지 않는다.

이름을 `tol_cmd_r`, `tol_cmd_lateral`, `tol_cmd_psi`로 바꿔 혼동을 막는다.

**같은 공간이지 같은 시험 조건이 아니다.** `tol_cmd`는 **사전 정의한 이산 시험에서 얻은 G1 비교 문턱**이다. 복귀와 배치 선별을 거친 조건의 값이고, 수집 조건 전체에 성립한다는 주장을 하지 않는다. 단계 사이 연속 구간의 성공도 보증하지 않는다. 실제 집기 성공은 G1 사람 배치 10회와 G3가 따로 판정한다. 조건 차이는 아래 경로 비교로 재서 값과 함께 보고한다.

AprilTag id 1과 번호만 같고 다른 마커다. **둘 중 하나라도 없으면 검출 실패다.** 측정은 화소와 각도로 기록하고 mm 환산값은 설명용으로만 쓴다. **집계에 넣지 않는다.** 측정값은 평행 이동만 보정하므로 **카메라 기하가 유지될 때의 영상 배치 지표**다. 이를 지키려고 `G0d-0` 시작 때 바깥쪽 마커 2개의 기준 위치를 고정하고, 사진마다 **각 마커가 기준에서 2화소를 넘으면 추가 쓰기 없이 멈춘다.** 2화소는 기존 207장 최대 0.90화소를 보고 정한 운영 한도다. 쥔 상태면 기존 실패 경로의 답 대기를 따른다. 멈춘 뒤 기준을 새로 잡으면 자연 흩어짐부터 새 버전으로 다시 재고 이전 기록과 합산하지 않는다.
- **3번에서 검출률이 충분하지 않으면 G0d 1차에 들어가지 않는다.** 기준은 3번 실행 전에 커밋한다. 정지에서 충분해야 다음으로 간다.
- 실행 중 분석 경로는 하나로 고정한다. 사진을 p620에서 Mac으로 가져와 `opencv-contrib-python-headless==5.0.0.93`으로 잰다. p620의 OpenCV 4.5.4는 같은 사진에서 id 7을 64장 중 59장만 잡아 쓰지 않는다(원인 미조사). 지연은 가져오기 0.17~0.32초, 검출 약 0.04초(실측 각 3회)다. 사진을 못 가져오면 검출 실패와 같게 쓰기 없이 멈춘다.

## `G0d-0` 자연 흩어짐

셀 3개(r_index 1, 4, 7, J1 90, J5 90), 오프셋 없음. 묶음 안에서 셀을 고정 순서로 교차해 놓기→집기 반복. 셀당 8회, 합 24회, 약 14분. 안전 조건과 쉼은 G0b와 같고 이미 G0a·G0b에서 본 범위다. 하강 전 확인은 없다(오프셋 자세가 없다).

**경로 비교**: 셀마다 일반 경로(놓기→`P` 집기) 뒤의 다음 `P` 놓기 사진과, 복귀 경로(놓기→`P+δ` 최소 단계 집기→`P+δ` 놓기→`P` 집기) 뒤의 다음 `P` 놓기 사진을 묶음 안에서 교차해 각 3회 찍는다. **G0d 1차의 오프셋 자세를 쓰므로 하강 전 확인과 받침 절차가 똑같이 적용된다.** 합 18회 더해 `G0d-0`은 42회다. 판단 기준: 두 경로의 위치·각도 분포가 같은 범위인가를 값으로 보고한다. **벗어나면 `tol_cmd` 전체를 `transfer=unverified`로 표시하고 G1 비교에 쓰지 않는다.** 벗어남의 정의(복귀 경로 편차가 일반 경로 최대를 넘음)는 실행 전 커밋한다. D5 원인 규명은 하지 않는다.

얻는 것:
- 셀별 **고정 기준** = 일반 경로의 위치·각도 중앙값.
- **자연 흩어짐** = 기준에서의 위치·각도 절대 편차 최대.
- 집기 성공률이 G0b 조건과 뚜렷이 다르면(1건이라도 실패) 마커 영향을 재검토한다. 원인 규명 없이 G0d 1차로 가지 않는다.

**배치 필터를 여기서 고정한다**: 편차 ≤ 자연 흩어짐 최대. 이것은 **관측 범위 기반 운영 필터**이고 `tol` 추정에 보수적이라는 근거가 아니다. 셀당 8회 최대라 표본에 민감하다. 결과를 본 뒤 조정하지 않는다. 원래 배치와 재적재 배치를 구분해 기록하고 탈락률을 보고한다.

## G0d 1차 프로토콜

### 단계

서로 다른 자세만 단계로, 셀·축·부호마다 **모델 오프셋 절댓값이 가장 작은 1단계**만.

| 축 | 셀 0 (r_index 1) | 셀 1 (r_index 4) | 셀 2 (r_index 7) |
| --- | --- | --- | --- |
| r (mm, 표 모델 차이) | −4.29, +5.62 | −5.55, +4.40 | −5.58, +3.95 |
| 횡방향 (mm, `r×ΔJ1`, J1 ±1) | ±2.17 | ±2.44 | ±2.71 |
| J5 | ±10° | ±10° | ±10° |

합 **18변형**. J1 회전에는 방사 방향과 그리퍼 방향 변화가 함께 있다. 축별 단독 시험이고, 세 축 동시 오차의 성공을 말하지 않는다.

### 시도 순서와 종결

- 변형마다 최대 5회. **4회 성공이면 통과, 2회 실패면 미달로 끝낸다.** 단계·결과열이 같을 때 5회 고정과 판정이 같다(32개 결과열 전수 불일치 0). 이전 안과 결과가 같다는 뜻은 아니다.
- 변형 순서: 셀·축·부호를 시드로 고정해 교차 진행. **결과를 본 뒤 순서를 바꾸지 않는다.**

### 한 시도

1. 블록을 쥔 상태에서 기준 자세 `P`에 놓기, `park`, 사진.
2. **배치 확인**: 윗면 마커 위치·각도가 기준 안인가. 검출 실패·벗어남이면 쓰기 없이 멈추고 사람 재적재 후 다시 잰다. 2회 연속이면 그 변형은 **미완료**로 끝낸다. 시도 소비 없음.
3. 오프셋 자세 `P+δ`의 `hover`로 이동해 멈춘다. `grasp` 쓰기 전이다.
4. **하강 전 확인**: 사용자가 양쪽 손가락의 하강 경로를 눈으로 본다. 답을 받아야 내려간다. 거부·판단 불가면 **안전상 미측정**으로 그 변형을 끝낸다. **여기부터 시도 시작이고 ID를 소비한다.**
5. `grasp`, 닫기, `hover`, `park`, 사진, 판정.
6. **판정 실패면 쓰기 없이 멈춘다**(아래 실패 경로).
7. **판정 성공이면 복귀**: `P+δ`에 도로 놓고(`hover`, `grasp`, 개방, `hover`, `park`), 사진과 배치 확인 뒤 `P`의 `hover`에서 **하강 전 확인을 똑같이 받고** 다시 집는다(`grasp`, 닫기, `hover`, `park`). 복귀 집기는 사진 판정하고 실패하면 실패 경로와 같게 멈추되 **시도 결과에 세지 않는다.** 그 수를 보고한다.

복귀를 모든 축에 넣는다. 축별 필요를 가려내는 시험을 늘리지 않으려는 선택이고 시간이 약 2배다. 쓰기 약 20회, 약 70초(경로 계산, 미측정).

### 집계

**사전 시험표가 기준이다.** 기록에 있는 셀만 세지 않는다.

- 축마다 출력: **`tol_cmd`(mm 또는 °), 시험 범위 상한, 미측정 사유, 확정 여부.**
- 18변형 전부 판정이 나면: 모든 셀·부호 통과면 `tol_cmd` = 그 축의 **단계 최솟값**(r 3.95 mm, 횡 2.17 mm, ψ 10°), `usable=true`. 어느 하나 미달이면 `tol_cmd=0`, `usable=false`이고 **그 축은 G1을 통과할 수 없다**(`p90=0`이 `≤0`을 만족하는 경우를 막는다).
- 안전상 미측정, 영상 무효, 예외 중단은 **미완료**다. **미완료가 있는 축은 `confirmed=false`이고 G1 입력에서 거부한다.** 전원 차단을 미달로 치환하지 않는다.
- `transfer=unverified`면 `usable=false`다.
- 통과해도 **시험 범위 안**의 이산 값이고 그 위는 미측정이다.
- 재개: 시도 ID 소비, 같은 ID 재실행 금지, 미실행만 재개. 미완료를 추가 표본으로 대체하지 않는다. 새 버전 기록과 합산하지 않는다.
- 오판정은 원 판정과 사람 관찰을 함께 보존하고 재채점하지 않는다. 판정값 고정(v9: 변화 ≥ 0.01, 노란색 영역 (585, 825, 150, 395)와 (565, 585, 250, 395)의 합 ≤ 100, 근거 `docs/261110-1008-G0d-판정값-재계획-플랜.md`). **윗면 마커가 노란 면적과 사진 차이를 바꾸므로** 판정 유효성은 위 거짓 성공 사진 시험으로 본다. 판정값이 안 맞으면 G0d 전에 플랜으로 조정하고 의존 검증을 다시 한다. G0d 데이터로 조정하지 않는다.

## G1 쪽 변경 (정본)
