## 1. 목적

정본 플랜 v2.2의 조건을 하나도 풀지 않고, 2026-11 기준 진보한 기술을 S1·G3에 넣는다.

지키는 조건:
- 「명시적 손–눈 변환 추정 없이」 학습한다는 주 방법의 주장.
- 허용 자세 표와 `SafeArm`·`SafetyGate`를 통한 쓰기만 허용(AGENTS 4번).
- 라벨 정의 「검증된 파지 명령 좌표」 `(r, φ, ψ)`, G0 결과와 G1~G3 판정 수치(AGENTS 6번).
- 5축 DOFBOT, 고정 Gemini 335L, 감독 세션, 리더 암 없음.

**조건에서 달라지는 점 하나**: 정본 §1 포트폴리오 문장은 「고정 RGB 카메라」다. depth를 입력에 넣으면(SP3 통과 시에만) 입력 주장이 「고정 RGB-D 카메라」로 바뀐다. 손–눈 주장은 그대로다. depth를 빼면 이 변경은 없다.

바뀌는 것: S1 모델의 백본과 입력, G3 기준선 1개 추가. 둘 다 정본 §8·§7 개정이다.

### 4.0 Spike (S1 첫날, 쓰기 0건)

| ID | 확인할 가정 | 방법 | 실패 시 |

| SP1 | DINOv2 가중치가 공개 저장소·포트폴리오 용도로 라이선스상 문제없다 | 모델 카드·LICENSE 원문 확인 | 다른 백본 후보 재선정 |
| SP2 | 백본이 Mac MPS와 p620 RTX 3090에서 돌아간다 | 1장 추론, 메모리·시간 실측 | 작은 변형으로 축소 |
| SP3 | 335L 정합 depth가 블록 윗면에서 유효값을 낸다(구멍·반사) | 기존 촬영 경로 `scripts/gemini_capture.py`로 정지 블록 10장, 유효 화소 비율 기록 | depth 입력 제외, RGB만 |

각 Spike 결과는 수치 기준을 **실행 전에** 커밋한다(AGENTS 6번).

### 4.1 정본 개정 (문서)

- §8 모델: 백본 후보, 대조군(ResNet18), depth 경로, 선택 규칙. **G1 검증 분할의 순차 선택은 헤드 A/B(대조군)를 포함해 총 3회 이하가 되지 않도록 변형을 최대 2쌍으로 제한한다. 각 쌍은 한 요소만 바꾼다**: ① ResNet18 RGB vs DINOv2 RGB(백본만) ② 앞의 승자 RGB vs 승자 RGB+depth(SP3 통과 시만). G1 검증 분할이 10표본뿐이라 변형을 늘리면 선택 편향이 G1 판정에 들어간다. 선택 지표와 동률의 수치 정의(예: 지표 차이가 어떤 값 미만이면 동률, 동률이면 단순한 쪽)는 M5에 G1 실행 전 커밋하고 G3 전에 고정한다.
- §7 시험 계약: 방법이 셋이 된다. 시행마다 순서 무작위화를 3방법으로 확장. T1 합격 판정은 **주 방법에만** 적용하고 기준선은 비교용이다.
- §1 포트폴리오 문장에 「최신 보정 기반 기준선과 비교」 추가(결과와 무관하게 사실대로). depth 채택 시 「고정 RGB」→「고정 RGB-D」.
- 일정: 방법당 N(T1 30, T2 20)은 그대로이고 방법이 2→3개라 G3 총 시행이 (30+20)×2=100 → (30+20)×3=**150회**(T1 60→90, T2 40→60)가 된다. G0e 주기로 재산정한다.

### 4.2 기준선 2 실행 경로

1. **보정 자료 수집**: G0a에서 이미 확인한 표 자세(`park`, 각 r의 `hover`)만 쓰고, 점이 한 평면 근처에 몰리지 않도록 G0a가 확인한 J1 3수준을 섞는다. 새 자세 없음. 각 자세에서 Gemini 1장. 세션 승인 필요(쓰기 있음).
2. **보정**: SP4 결과의 방법으로 카메라→`base_link` 변환을 추정. FK는 `kinematics.py`의 모델 값이며 **모델 값이라고 기록**한다(AGENTS 7번).
3. **자세 추정**: depth 점군에서 작업대 평면 제거 → 블록 점군 → 최소 외접 사각형 → `base_link`의 (x, y, yaw).
4. **표 투영**: (x, y, yaw) → (r, φ, ψ) → 허용 자세 표의 가장 가까운 항목. 표에 없거나 범위 밖이면 `REJECT`(정본 §8 실행 검사와 같음).
5. 실행은 주 방법과 같은 `SafeArm` 경로.

**G3 고정 규칙**: 정본 §7의 SHA-256 기록 목록에 **보정 방법과 보정 결과 파일**을 추가하고, G3 세션의 영상으로 다시 보정하지 않는다(AGENTS 6번을 기준선에도 적용).

기준선 2는 G2 수집 표본으로 **학습하지 않는다**(보정 기반이라 라벨이 필요 없다). 보정 품질은 G2 표본에서 투영 명령과 라벨의 차이로 보고만 한다. 이 차이에는 보정 오차뿐 아니라 **FK 모델의 절대 오차(R2·R12)와 놓인 결과의 흩어짐(R16)이 섞인다**. 보정 오차만으로 해석하지 않는다.

### 4.3 직전 교차검토에서 넘어온 항목 (같이 처리)

- 윗면 마커 한 변 자 실측 → 마커 4코너 국소 평면 mm 변환을 **측정 전용**으로 추가.
- `G0d-0` 흩어짐을 축별(r, 횡)로 분리 보고.
- 기준 마커 2화소 정지 검사를 G2·G3에도 적용(카메라가 움직이면 학습 모델과 기준선 2의 보정이 모두 무효).
- G1 판정에 「같은 영상에 여러 유효 명령」 모호성 반영(M4 잔여 항목).
