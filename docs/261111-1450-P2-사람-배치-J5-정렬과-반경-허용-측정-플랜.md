# P2 사람 배치 J5 정렬 시험 + R1 반경 허용 측정 플랜 (초안, 승인 요청)

작성: 2026-11-11 KST. 사용자 지시: 「사람이 놓는 블록으로 J5 정렬을 검증하는 시험」과 「반경 허용 측정이나 J5 극단을 쓰는 시험」 둘 다 진행. **승인 전이다. 팔에 명령을 보내지 않았고 코드도 바꾸지 않았다.** 앞선 결과: `docs/*CH-3-J5-정렬-연쇄-40시도-결과.md`(38/40, 한계 3절), `docs/*J5-블록-방향-정렬-분석과-계획.md`. 사람 개입 최소화 정책(메모리 `minimize-human-in-measurement`)을 적용한다.

## 1. 두 시험이 답하는 질문

| 시험 | 질문 | CH-3이 못 답한 이유 |
| --- | --- | --- |
| **P2** 사람이 놓은 블록 + J5 정렬 | 사람이 **임의 방향**으로 놓은 블록을 L1(위치) + J5 정렬(방향)만으로 집는가. J5 극단(60~120 끝)에서도 되는가 | CH-3은 팔이 놓은 블록만 집었다(쉬운 시험). J5는 78~98만 썼다 |
| **R1** 반경 허용 | 손이 블록 중심에서 반경 방향으로 얼마나 벗어나도 집히는가(L1 반경 오차 σ 약 4 mm 대비 여유) | 모의는 횡방향만 봤다. 반경 허용은 측정한 적이 없다(`docs/*연쇄-시험-구현과-L2-반올림-계산-결과.md`) |

J5 극단은 P2가 겸한다(방향을 ±30° 부근까지 흩어 놓아 J5 약 63~117을 쓴다). 별도 J5 시험은 두지 않는다.

## 2. P2 설계

- **블록 놓기(사람)**: 구역(J1 72~108, r 128~160 mm: P1에서 r 125 이하는 구역 밖 거절 2건)에 **방향은 자유롭게** 눕혀 놓는다. 정렬 왕복이 없다. 목표 20자리·방향(반경선 대비 d −30~+30°)을 시드로 뽑아 SVG로 보이되 **L1에는 놓은 뒤 측정한 값을 넣는다**(P1과 같은 규칙). 방향 d가 J5 보정 범위(60~120)를 넘으면 그 시도는 세지 않고 새 자리(최대 1회 재배치).
- **시도**: `plan_aligned`로 (r_index, J1, J5) → 집기(`run_p1` 경로: park → hover(확인) → grasp → 닫기 → hover → park 5초 → 같은 자리에 도로 놓기) → 자동 판정(관찰기 그리고 서보 6 판독 ≤ 151, P1과 같음). 사람은 시도마다 「놓았다」 한 번이다(도로 놓은 블록을 집어 새 자리에 놓는 것이 곧 치우기).
- **하강 확인**: 처음 한 번 + **J5 편차가 이전 확인 최대보다 10° 이상 커질 때마다**(J5 상승 확인: 약 10°, 20°, 30°, 이후 없음). CH-3의 「첫 J5≠90만」보다 엄격하다. 이유: J5 78~98 밖은 실기에서 처음이다.
- **J5 상승 확인 이후**는 전원 차단 감독이다.
- **판정(사전 고정)**: 20시도 합격 ≥ 18/20(P1과 같은 규칙, 방향이 자유라 더 어려운 시험), 불합격 ≤ 15/20, 16~17이면 20시도를 더해 40시도(합격 ≥ 36/40). 모든 실패는 원인(밀림, 내려앉음, 낙하, J5 극단)과 그때의 J5·방향을 기록한다. 보고: |J5−90| 구간(≤10°, 10~20°, 20~35°)별 성공, 방향 측정 d 분포, 집기 전후 블록 각도 변화(비틀림).
- **사람 접점**: 시도당 사용자 메시지 1개(「놓았다」). 20시도 약 40분(시도당 약 2분), 쓰기 약 11회 × 20 = 220.

## 3. R1 설계 (사람 개입 0, 연쇄)

연쇄 시험(`run_chain --align`)에 **반경 오프셋 일정**을 붙인다. 집는 자리를 L1이 정한 행에서 `Δ`행 옮긴다(손만 반경으로 이동, 블록은 그대로). `Δ` 일정은 시드로 고정한다.

- 표 행 간격은 4.0~6.0 mm(`r` 119.8, 124.0, 129.7, 134.1, 139.7, 144.1, 149.6, 155.1, 159.1, 165.1). `Δ ∈ {−3, −2, −1, 0, +1, +2, +3}`행은 대략 −15 ~ +17 mm다. 각 `Δ`를 **6번씩 42시도**, 순서는 시드 섞기. 집는 행이 표 밖(0~9 밖)이면 가능한 가장자리로 자르고 **실제 오프셋을 기록**한다.
- **오프셋은 L1 추정 대비**이다. 블록의 실제 중심 대비는 L1 반경 오차(σ 약 4 mm)가 섞여 흐려진다. 성공률 곡선은 이 한계를 적고 낸다(곡선의 폭 = 허용 + 노이즈).
- 안전: 오프셋 최대 약 17 mm는 블록 길이 60 mm의 절반(30 mm) 안이다. 손가락은 블록 폭 방향을 가로질러 내려가므로 윗면에 내려앉는 위험은 횡방향 오프셋보다 작다(횡방향이 아님). 처음 몇 번 하강은 사용자 눈 확인(P2와 같은 J5 상승 확인 규칙에 오프셋 상승 확인 추가: 처음 |Δ| = 1, 2, 3 각 한 번).
- 판정 없음(측정). 보고: `Δ`별 성공/시도, 실패 모양(밀림, 반쪽 집기), 허용 폭 추정(성공률이 0.9 아래로 내려가는 오프셋)과 한계.
- **사람 접점 0**(시작 적재와 확인뿐). 쉼: 10번 닫기마다 **10분**(CH-3에서 5분은 부족했다). 42시도 약 25분 + 쉼 4번 40분 = 약 65분.

## 4. 구현 (승인 후)

1. `run_p1`이 J5를 쓰도록(`trial["j5"]`) 고치고 `p1-pick --j5`와 J5 상승 확인(`confirmed_dev`) 추가. Fake 시험.
2. `run_chain`: 반경 오프셋 일정(`--offset-schedule`), 오프셋 상승 확인, 쉼 시간 인자. Fake 시험.
3. `scripts/p2_targets.py`(20자리·방향 시드, SVG 안내), `scripts/r1_schedule.py`(42시도 오프셋 일정).
4. 1단 sanity: P2 1~2시도, R1 2~3시도(쓰기 약 30~35회씩). 합격은 기계적(J5 쓰기, 확인 동작, 기록).

## 5. 순서와 부하

두 시험은 순서대로 한다. 같은 하루에 연속하지 않고 그리퍼를 쉰다. R1(사람 없음)을 먼저 하고 P2(사람 필요)를 이어 한다. 쓰기 합계 약 220 + 460 = 680회(P2 상한 260, R1 상한 500). 각 실행 전 단위 sanity로 쓰기·주기를 재고 승인을 요청한다.

## 6. 하지 않는 것

판정 규칙·문턱 변경, 사후 완화, 사람 배치에서 방향 맞춤 요구, J5 60~120 밖, 횡방향 허용 측정(별도 계획), 관찰기 영역·한계 변경(종이띠 유지).

## 7. 위험

| 위험 | 대응 |
| --- | --- |
| J5 극단에서 손 yaw 모델(J5 60·90·120 세 수준) 비선형 | P2에서 J5 편차별 성공을 보고, 실패 시 모델 한계로 기록 |
| 방향이 큰 블록에서 손가락이 블록 위에 내려앉음 | J5 상승 확인, 전원 차단. P2는 사람이 지켜본다 |
| R1 오프셋이 L1 노이즈에 묻힘 | 한계를 적고 곡선 폭으로 해석. 필요하면 후속 계획 |
| 그리퍼 과열 | 쉼 10분(10번 닫기마다), 사용자가 알려 오면 정지 파일 |
| 관찰기 오판정 재발 | 종이띠 확인 사진(오른쪽 띠 노란 화소 0 근처)을 각 실행 시작 전에 찍는다 |
