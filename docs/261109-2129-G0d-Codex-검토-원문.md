1. **전원 차단을 예정된 충돌 회피 수단으로 쓰지만, 중력 낙하의 안전 조건이 없습니다.**

   근거: `플랜:46–47, 81–87`; `docs/G0-RUNBOOK.md:27–31`; `src/learned_grasp/safety.py:3–4, 83–92`.

   횡방향 ±10 삭제는 위험 노출을 줄이지만 남은 단계의 안전을 입증하지 않습니다. 2단계 시작 전 승인은 내려오는 손가락을 멈추는 장치가 아닙니다. 특히 사용자가 확인한 대로 전원 차단 시 팔이 낙하하므로, 블록 위에서 차단하면 충돌을 더 진행시킬 수 있습니다. 소프트웨어 종료도 진행 중인 이동을 멈추지 않습니다.

   **수정안:** 하강 전에 개방 손가락과 블록의 실제 여유, 접근 경로, 차단 시 팔·블록의 낙하 범위 및 받침을 확인하는 별도 진입 조건을 두십시오. 여유를 입증하지 못한 단계는 실행하지 않고 **안전상 미측정**으로 남겨야 합니다. 확인은 횡방향 2단계뿐 아니라 미검증 r·J5 조합에도 적용해야 합니다. 전원 차단은 긴급 수단으로 유지하되 예정된 시험 종결 수단으로 삼지 마십시오. 필요한 여유 수치는 현재 자료로 정할 수 없습니다.

2. **r 복귀와 횡방향·J5 복귀 생략 모두 초기 상태 복원을 보장하지 못합니다.**

   근거: `플랜:55–59, 114–115`; `src/learned_grasp/g0_runner.py:157–170, 243–255`; `AGENTS.md:14–15`.

   r 복귀는 손 안 상대 위치가 운반 중 유지되고 놓을 때 끌리지 않는다는 조건에서 합리적입니다. 그러나 기준 자세에서 다시 집는 동작 자체가 재정렬을 보장하지는 않습니다. 횡방향·J5 자기 정렬도 검증 전 가정입니다. 사후 사진에서 문제가 발견되면 이미 뒤 시도들의 실제 오프셋까지 오염될 수 있습니다.

   **수정안:** 모든 축에 대해 **오프셋 집기 전 배치 유효성 확인**을 넣고, 별도 교정에서 복귀 또는 자기 정렬이 확인된 경우에만 자동 연속 실행을 허용하십시오. 사진은 직전 사진과의 차이뿐 아니라 셀별 고정 기준 위치·각도와 비교해야 합니다.

   임계값은 G0d 결과를 보기 전에 다음 근거로 정해야 합니다.

   - 정지 블록 반복 촬영으로 위치·각도 측정의 반복성 확인
   - mm 환산, 카메라 이동, 마커 가림 및 검출 실패 처리 확정
   - 별도 배치·복귀 교정으로 잔류 오차 확인
   - 단계 구분에 허용할 초기 배치 오차와 측정 불확실성의 예산 설정

   예를 들어 `관측 편차 + 측정 불확실성 ≤ 사전 배치 허용오차`를 유효 조건으로 정의할 수 있습니다. 허용오차의 숫자는 현재 자료만으로 제시할 근거가 없습니다. “판정 임계값이 아니라 유효성 확인”이어도 데이터 채택 여부를 바꾸므로 사전 고정 대상입니다.

3. **첫 실패 확인이 자동 복구보다 앞서는지 불명확하고, 오판정 시 안전 상태가 정의되지 않았습니다.**

   **수정안:** 새 실행기에 자동 복구 명령 **전** 확인 지점을 명시하십시오. 실제 미파지, 실제 파지, 상태 불명, 영상·조회 오류를 분리하고, 상태 불명에서는 추가 자동 쓰기를 막아야 합니다. 사람이 접근하기 전 팔 지지·물체 회수 절차도 정해야 합니다. Fake 검증에는 실패 분기 진입 후 승인 전 쓰기 0건, 복귀 집기 실패, 중단·재시작 경로를 포함하십시오.

4. **“판정이 같다”는 주장이 조기 종결의 논리적 동등성을 넘어 확장돼 있습니다.**

   근거: `플랜:45, 51, 63`; `src/learned_grasp/g0_runner.py:132–150`.

   동일한 5개 이진 결과열에서 4성공 또는 2실패로 멈추는 규칙은 정확합니다. 읽기 전용 Python으로 전수 확인한 실제 출력은 다음과 같습니다.

   ```text
   5개 이진 결과열 32개: 판정 불일치 0개
   ```

   작은 단계 미달 후 큰 단계를 생략하는 것도 기존의 연속 통과 집계와 논리적으로 맞습니다. 그러나 순서·복귀·총 닫기 횟수가 바뀌면 열과 블록 상태가 달라져 실제 결과열 자체가 바뀔 수 있습니다. 따라서 기존 240회 실험과 결과가 같다고 보장할 수 없습니다.

   **수정안:** 동등성 주장을 “동일 단계·동일 결과열에 대한 4/5 판정”으로 한정하십시오. 가능한 묶음들을 사전 고정 순서로 교차 진행해 축과 시간의 결합을 줄이고, 기준 자세 확인도 고정 주기로 넣으십시오. 표류 기준과 발견 시 처리 범위를 사전 확정하고, 결과를 본 뒤 축 순서를 바꿔 유리한 실행을 채택하는 절차는 삭제해야 합니다. SDK 조회와 사진은 서로 다른 관측값으로 보존하십시오.

5. **새 `tol` 정의와 중단·미측정 상태의 집계 규칙이 부족합니다.**

   **수정안:** 사전 시험표를 집계의 기준으로 삼아 다음을 명시하십시오.

   - 셀·부호마다 작은 단계부터 연속 통과한 최대값을 계산한 뒤 전체 최솟값 산출
   - 첫 단계의 유효한 시험 미달은 0
   - 안전상 미실행·영상 무효·예외 중단은 시험 미달과 구분
   - 필수 묶음 미완료 시 확정 `tol` 발행 금지
   - 상한까지 통과해도 그 밖은 미측정이며, 단계 사이 연속 구간 전체의 성공을 입증한 것은 아님

   특히 전원 차단 사건을 바로 해당 단계의 4/5 미달로 치환하지 마십시오. 안전상 상한 제한과 통계적 미달은 별도 상태여야 합니다.

6. **“실제 오프셋”이 모델 좌표와 물리 실측을 혼동하게 합니다.**

7. **정본 개정 자체는 사후 변경이 아니지만, 재실행·재판정 규칙은 사후 선택을 허용합니다.**

추가·잔존 수정 사항은 다음과 같습니다. 아래 **MAJOR는 구현 전체의 착수 차단이 아니라 해당 기능 확정 또는 실기 진입 전 해결 사항**입니다.

1. **MAJOR — 첫 시도의 하강 확인을 이후 배치에 재사용할 근거가 없습니다.**  
   근거: [플랜:90](docs/261109-2129-G0d-재설계-플랜.md:90), [플랜:114](docs/261109-2129-G0d-재설계-플랜.md:114). 복귀·사람 재적재·묶음 재개로 물체 상태가 달라집니다. 배치 허용치 이내라는 사실도 손가락 경로의 비접촉을 자동으로 보장하지 않습니다. `SafetyGate` 역시 물체 충돌 검사가 아닙니다([safety.py:55](src/learned_grasp/safety.py:55)).  
   **수정안:** 초기 구현은 매 오프셋 하강 직전 확인으로 두고, 양쪽 손가락의 **하강 경로 전체**를 관찰할 수 있어야 승인하도록 명시하십시오. 재적재·재개·관찰 조건 변화는 이전 확인을 무효화하고, 보이지 않거나 판단이 어려우면 안전상 미측정으로 남깁니다.

2. **MAJOR — 낙하받이 확인과 30초 만료 대응이 실행 규칙으로 부족합니다.**  
   근거: [플랜:98](docs/261109-2129-G0d-재설계-플랜.md:98), [플랜:110](docs/261109-2129-G0d-재설계-플랜.md:110), [플랜:134](docs/261109-2129-G0d-재설계-플랜.md:134). “받침 확인”만으로 팔의 낙하를 제한하는지, 블록만 받는지 알 수 없습니다. 30초에 차단 여부를 판단하면 한도가 실제로 지켜지는지도 불명확합니다.  
   **수정안:** 실기 승인 전에 받침의 보호 대상·낙하 경로·손을 넣지 않는 처리 절차를 기록하고, 해당 자세에서 확보하지 못하면 실행하지 않도록 하십시오. 30초는 안전 보증이 아닌 운영 한도로 명시하고, 만료 전 경고와 만료 시 세션 종료·추가 쓰기 차단을 Fake로 검증하십시오. 물리적 처리는 사전 합의된 절차가 있어야 합니다.

3. **MAJOR — 배치 유효성에 위치뿐 아니라 회전과 측정 불확실성이 필요합니다.**  
   근거: [플랜:51](docs/261109-2129-G0d-재설계-플랜.md:51), [플랜:61](docs/261109-2129-G0d-재설계-플랜.md:61), [플랜:114](docs/261109-2129-G0d-재설계-플랜.md:114). 정지 반복성은 정확도와 다르고, 마커 한 변 길이만으로 원근·관측면 차이까지 처리되는 것은 아닙니다. 회전 잔류가 있으면 `tol_ψ`의 초기 조건도 달라집니다.  
   **수정안:** 모든 축·모든 오프셋 집기 전에 고정 기준 대비 위치와 회전을 확인하도록 명시하십시오. `G0d-0`에서 측정 좌표계, 환산 방식, 위치·각도 반복성, 검출 실패 처리, 각각의 허용치를 고정하십시오. 복귀 생략은 배치 확인 생략을 뜻하지 않도록 분리해야 합니다.

4. **MAJOR — 안전상 미측정은 성공 허용오차의 상한이 아닙니다.**  
   근거: [플랜:120](docs/261109-2129-G0d-재설계-플랜.md:120), [플랜:123](docs/261109-2129-G0d-재설계-플랜.md:123). 예를 들어 작은 단계 통과 후 큰 단계를 안전상 생략했다면, 큰 단계의 성공 여부는 모릅니다. 또한 음수 방향의 “최대 모델 오프셋”은 절댓값 기준인지 명시해야 합니다.

5. **MAJOR — 재개 시 불리한 기록이 빠지지 않는 규칙이 필요합니다.**  
   근거: [플랜:126](docs/261109-2129-G0d-재설계-플랜.md:126), [플랜:163](docs/261109-2129-G0d-재설계-플랜.md:163). 원본 보존만으로 같은 단계 재실행과 유리한 실행 선택을 막지는 못합니다. 기존 실행기는 중단된 시도를 남은 시도에서 제외합니다([g0_runner.py:230](src/learned_grasp/g0_runner.py:230)).
