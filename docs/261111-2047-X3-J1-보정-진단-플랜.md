# X3 J1 오프셋 보정 진단 플랜 (초안, 승인 요청)

작성: 2026-11-11 KST. 사용자 지시 「푸시하고 제안 진행」(X2 A 결과의 제안). **승인 전이다. 팔에 명령을 보내지 않았고 코드도 바꾸지 않았다.** 앞선 결과: `docs/*X2-A-횡방향-오프셋-24시도-결과.md`(24/24 성공, J1 보정 진단 −5.4°가 사전 문턱 3°를 넘어 B 보류), `docs/*X2-횡방향-허용-측정-플랜.md` 4.1.

## 1. 질문

J1을 `Δ`° 옮겨 집을 때 **손과 블록의 방향 어긋남이 Δ에 따라 달라지는가**(= J5 보정식 `d' = 블록 각도 − 집는 자리 반경선`이 맞는가). X2 A에서는 놓인 뒤 방향 잔차(실측 − 예측) 평균이 Δ−1 뒤 +2.1°(n 8), Δ0 뒤 +1.9°(8), Δ+1 뒤 −3.3°(6)였고 「+1 뒤 − −1 뒤」 D = −5.4°(표준오차 약 2.9°)였다. 표본이 작아 결론을 못 내렸다.

## 2. 설계 (연쇄, 사람 접점 0, 기존 `chain --x2`)

- **같은 시험을 표본만 늘린다.** J1 오프셋 일정 `config/x3.json`: Δ −1 × 16, +1 × 16, 0 × 8 = **40시도**(섞음, 시드 고정). 놓는 손 J1은 공칭(재중심 확인됨), 자리는 행 3~6·J1 76~104, 블록 모양 점검은 한계 재설정본.
- X2 A의 24시도(Δ 각 8)와 합쳐 **Δ+1 24, Δ−1 24, Δ0 16**이 된다. D의 표준오차는 약 3.4°/√24 × √2 ≈ **1.0°**로 줄어 ±3°를 3σ로 가른다.
- 안전은 X2 A와 같다(Δ ±1, 실제 횡방향 ±4.5 mm, 걸림 확률 약 2%). 확인: 프로세스 시작 시 첫 집기·방향별 첫 오프셋 집기. 쉼 10분 × 3(닫기 10, 20, 30번 뒤). 쓰기 약 401회(상한 420), 약 55분.
- **사전 고정 판정**(통계량 D = 「+1 뒤 잔차 평균 − −1 뒤 잔차 평균」, X2 A + X3 합산, 표준오차와 95% 신뢰구간 보고. 사람이 다시 놓은 블록은 제외):

| 결과 | 해석 | 다음 |
| --- | --- | --- |
| \\|D\\| ≤ 3° 이고 95% 구간이 0을 포함 | 보정은 문제없음. X2 A의 −5.4°는 우연 | B(±2°)를 별도 승인으로 진행 |
| D < −3° 이고 구간이 0을 제외 | **과보정**(보정이 실제보다 큼)이거나 +J1 쪽 닫기 비대칭 | 보정 계수를 1에서 줄이는 방향으로 별도 계획·재진단. B 보류 |
| D > +3° 이고 구간이 0을 제외 | 보정이 모자라거나 부호 오류 | 같은 방식으로 별도 계획. B 보류 |
| \\|D\\| > 3°이나 구간이 0을 포함 | 표본 부족 | 표본을 더 늘릴지 결정(최대 1회 더) |

- 부호 해석 메모: 집을 때 손-블록 어긋남이 Δ에 따라 `ε × Δ`(도)이고 어긋남이 놓인 방향으로 이월되는 기울기가 s(앞 CH 4쌍에서 약 +1~2, 불확실)면 D = 2εs다. 보정이 없으면 ε ≈ +1.3(D > 0), 부호가 반대면 +2.6(D > 0), 과보정이면 ε < 0(D < 0)이다. **X2 A의 D = −5.4°는 부호상 과보정 쪽**이나 s가 불확실해 크기는 말하지 않는다. 이월 기울기 s를 따로 잰 값은 없다.
- 부가 분석: 놓인 뒤 방향 잔차를 Δ로 회귀(기울기 ± 오차), Δ0 대조로 L1 치우침 제거, 집는 전 방향 d와 집기 J5 대 결과(성공 여부). 놓인 블록 J1 대 손 J1(재중심) 재확인.
