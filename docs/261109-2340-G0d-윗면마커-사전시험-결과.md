## 불합격 원인

C 반대 방향 5장에서 윗면 마커 id 7은 5/5 잡혔고, 기준 마커 id 1이 0/5다. 사진에서 돌린 블록이 id 1의 모서리를 가린다. 측정이 두 마커를 함께 요구해 값이 비었다. 원인 분석은 `docs/*-G0d-보드마커-가림-이슈보고서.md`에 적는다.

```text
C-rotm-00 {7: [704.2, 341.6]} rej 646
C-rotm-04 {7: [704.3, 341.6]} rej 603
C-rotm id7 단독 각도 차이(진단, 판정 아님) 15.65
```

15.65°는 계약 판정이 아니고 합격으로 바꾸는 근거로 쓰지 않는다.
