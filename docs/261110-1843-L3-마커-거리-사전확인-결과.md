# L3 컬러+마커 거리 추정 사전 확인 결과 (저장된 영상, 쓰기 0건)

2026-11-10 KST. **장치 명령 0건, 새 촬영 0건.** DB-1~DB-3에서 저장한 DaBai 컬러 영상(`data/dabai/view/*/color.png`)에서 보드 AprilTag(36h11 id 1)를 검출해 변 길이(화소)를 재고, 핀홀 식으로 거리를 계산했다. 하드웨어 제약판 플랜 §3.4(L3 컬러+마커)의 가능성 확인이다. 판정 게이트가 아니다.

## 1. 방법

- 검출: OpenCV 5.0.0 `aruco`, `DICT_APRILTAG_36h11`, id 1(보드 마커). 영상은 책이 마커를 가린 DB-3-1·DB-3-2와 마커가 시야에 없는 park 시험 영상을 제외한 8장(hover 4장, grasp 4장)이다.
- 거리 = fx × 실제 한 변(mm) / 변 화소 수. 컬러 fx 479.07(`docs/261110-1203-…` 측정 내부 파라미터). **보드 마커의 실제 한 변은 아직 재지 않았다.** 블록 끝면 마커 실측값 19.5 mm(`docs/261109-2158-블록-마커-측정-결과.md`)를 같은 종류 마커로 가정해 계산한다(가정).

## 2. 결과

| 영상 | 자세 | 회색 영상 변 길이(화소) | 빨강 채널 변 길이(화소) |
| --- | --- | --- | --- |
| db1-hover | hover | 56.0 | 56.0 |
| db2-hover-c1 / c2 | hover | 55.0 / 55.3 | 55.5 / 55.3 |
| db3-0-hover | hover | 55.3 | 55.8 |
| db1-grasp | grasp | 73.6 | 74.0 |
| db2-grasp-c1 / c2 | grasp | 74.0 / 74.0 | 74.0 / 74.0 |
| db3-0-grasp | grasp | **검출 실패** | 74.0 |

- **검출률**: 회색 영상 7/8, **빨강 채널(또는 채널 최솟값) 8/8**. `db3-0-grasp`는 마커가 영상에서 선명히 보이는데 회색 변환으로는 놓쳤다(과노출된 흰 배경 위 푸른 마커의 대비 부족). 빨강 채널에서는 푸른 마커가 어둡게 나와 검출됐다.
- **재현성**: 같은 자세를 세션이 다르게 찍은 값이 `hover` 55.0~56.0화소(약 ±0.5화소), `grasp` 73.6~74.0화소(약 ±0.2화소)로 거의 같다. 거리로 바꾸면 변 길이 한 화소가 `hover`에서 약 1.8%(약 3 mm), `grasp`에서 약 1.4%(약 1.7 mm)다.
- **거리(변 19.5 mm 가정)**: `hover` 약 168~170 mm, `grasp` 약 126 mm. 깊이 중앙값(`hover` 171~175 mm)과 `hover`에서 약 3~7 mm 차이고, **깊이가 거의 안 나오는 `grasp`에서도 거리가 나온다.**
- 자체 일관성: 모델 거리(`hover` 172.4, `grasp` 124.0)를 쓰면 마커 한 변이 `hover` 19.9 mm, `grasp` 19.2 mm로 나와 두 자세에서 비슷하다. 이 일치는 모델 거리에 의존한다(독립 증거가 아니다).

## 3. 의미와 한계

- **컬러+마커는 DaBai 깊이가 못 쓰이는 `grasp`(약 126 mm)에서도 거리를 준다.** 플랜 L3의 방향(깊이 대신 컬러+마커)을 이 사전 확인이 지지한다.
- 한계: 보드 마커 실제 크기 미측정(가정 19.5 mm), 줄자 대비 정확도 없음, 같은 두 자세만 봤다(다른 거리·각도 없음), 표본이 적다(자세별 4장, 서로 독립이 아님).
- **검출 전처리가 필요하다**: 회색 변환만 쓰면 과노출 장면에서 놓친다. 빨강 채널(또는 채널 최솟값)을 쓴다. 노출을 고정하지 않았다(`enable_color_auto_exposure` 기본 false지만 값은 `-1`, 영상은 과노출).
- 블록 윗면 마커(id 7, 25.39 mm)는 이 영상들에 없다. 블록을 놓고 찍는 시험이 필요하다.

1. 보드 마커 한 변을 자(또는 캘리퍼스)로 재서 기록한다(쓰기 없음).

3. 다른 높이(책 위 등)에서 마커 거리를 줄자 값과 비교한다.
