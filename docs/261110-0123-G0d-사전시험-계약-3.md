## 자리

블록의 긴 변은 베이스에서 YAHBOOM 글자 쪽을 향한다. 자리는 눈대중이고 실제 셀을 재현한다고 주장하지 않는다.

```text
    [ 베이스 ]
        P1: 베이스와 보드 마커 사이, 보드 마커가 보임
    [보드 마커]  P3: 이 위를 덮어 보드 마커가 안 보임
    YAHBOOM 글자
```

돌림은 베이스 쪽 끝을 두고 글자 쪽 끝만 민다. 한 방향 약 1 cm(윗면 60.33 mm에서 계산 약 9.4°), 이어서 반대쪽으로 약 2 cm. 눈대중이다. 이어서 밀림, 치움을 찍는다.

경계 잔류 E1~E3는 계약 2와 같다. 분홍 표시 반대쪽과 글자 쪽이 만나는 종이 모서리, 분홍 표시 쪽 가장자리, 글자 쪽 가장자리다. 블록 전체가 종이 위에 있어야 한다.

## 미리보기 (시험 사진 전)

- P1, P3 정지 촬영 직전 사진 1장으로 **보드 마커 id 1의 검출 여부만** 본다. P1은 보여야 하고 P3는 안 보여야 한다. 맞을 때까지 다시 놓는다. 시도 횟수는 `preview_attempts`에 남는다.
- 측정 사진을 찍기 전이라 재촬영이 아니다. 미리보기에서 **윗면 마커 id 7의 값과 바깥쪽 마커 위치를 쓰지 않는다.** 시작 조건은 id 0, 1의 존재만 본다.
- E1~E3 촬영 직전에도 미리보기 1장으로 **id 0, 1의 존재만** 본다. 판정용 사진이 기준 마커를 가려 측정 합격을 깨는 일을 막기 위해서다. 안 보이면 다시 놓는다.
- 미리보기는 정지·판정 계산에 넣지 않는다.
- 미리보기 사진을 찍거나 가져오지 못하면 시험 사진을 찍지 않고 다시 확인한다.
- P1은 보드 마커가 보이는지만 확인한다. 베이스 쪽인지는 자동으로 확인하지 않는다. 다른 쪽에 놓아도 보드 마커가 보이면 통과하고, 계약상 무효는 아니다.

## 유효 조건 (성능 판정보다 먼저)

P1 정지에서 id 1 **≥ 9/10**, P3 정지에서 **≤ 1/10**. 찍기 전 사용자 `y`(P3, E1~E3)가 `shoot_log.json`에 있어야 한다. `fetch` 뒤 `analyze` 전에 Claude가 P3 정지 사진을 보고 덮임을 결정해 결과 문서에 **커밋한다.**

P3가 무효면 성능을 계산하지 않고 이 계약을 끝낸다. E 확인이 빠지면 `judge_pass`는 `null`이다. 다시 찍기는 없다. 찍기 시작한 뒤 중단해도 그 사진으로 판정하지 않고 새 계약으로 간다.

## 합격 기준

한 장의 「검출」은 윗면 id 7과 바깥쪽 id 0, 1이 **모두** 잡힌 경우다.

| 구분 | 시험 | 기준 |
| --- | --- | --- |
| 측정 | 정지 검출 | 자리마다 **≥ 9/10** |
| 측정 | 돌림 검출 | 자리·방향마다 **≥ 4/5** |
| 측정 | 방향 구분 | 정지 평균과의 `image_angle` 차이 **≥ max(5°, 정지 std × 3)** |
| 측정 | 두 방향 | 두 돌림의 부호가 **서로 반대** |
| 측정 | 위치 구분 | 돌림 평균과 정지 평균의 거리 **≥ max(2화소, 정지 2차원 RMS × 3)** |
| 측정 | 카메라 | **47장 전부**에서 id 0, 1이 잡히고, 각각 자기 중앙값에서 **≤ 2화소** |
| 판정 | 거짓 성공 | P1·P3 첫 정지 대비 나머지 정지 9장, 돌림 10장, 밀림 1장 합 **20장씩**, 하나라도 성공이면 G0d 진입 금지 |
| 판정 | 경계 잔류 | P1 첫 정지 대비 E1~E3, 하나라도 성공이면 G0d 진입 금지 |
| 판정 | 제거 | 치운 사진은 **성공**. 실패면 거짓 실패로 G0d 진입 금지 |

**측정과 판정은 따로 합격한다.** 판정이 미달이어도 측정 합격은 유효하다. 그 경우 G0d에 들어가지 않고 판정값을 플랜으로 재계획한 뒤 판정 부분을 새 계약과 새 사진으로 본다. 카메라, 마커, 배치, 측정 코드가 바뀌면 측정도 다시 본다. 실패 기록은 그대로 남긴다.

판정값은 변화 ≥ 0.02, 노란 화소 ≤ 100으로 고정이다. 같은 계약으로 다시 찍어 통과시키지 않는다. 카메라·위치 2화소는 운영 한도이고 검증된 물리 한도가 아니다.

## 합격이 뜻하는 것

고정 카메라에서 검출, 방향 변화, 눈에 띄는 위치 변화를 구분할 수 있다는 뜻이다. 판정 합격은 찍은 배치에서 거짓 성공이 없었다는 뜻이다. mm·도 정확도, 배치 필터의 충분성, 실제 셀 r1·r4·r7의 검출, 파지 영향, 조명 변화는 말하지 않는다. 앞의 것들은 `G0d-0`에서 본다.

마커가 둘이라 하나가 가려지거나 움직이면 대신할 마커가 없다. 그때는 쓰기 없이 멈춘다. 측정값은 평행 이동만 보정한다.
