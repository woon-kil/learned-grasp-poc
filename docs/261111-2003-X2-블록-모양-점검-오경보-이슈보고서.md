# X2 블록 모양 점검 오경보 이슈 보고서

작성: 2026-11-11 KST. 관련: `docs/*X2-횡방향-허용-측정-플랜.md` 4.1, 세션 `runs/X2-1`(gitignore).

## 현상

X2 A 단계(24시도) 3번째 시도 전에 `chain-003: 블록 모양이 이상해 시도하지 않는다(면적 비 1.58, 긴/짧은 변 1.75)`로 멈췄다. 쓰기는 21회, 팔은 park, 블록은 정상(사진 확인: 눕혀져 있고 옆면이 보임).

## 원인

advisor 지적으로 추가한 블록 모양 점검의 한계를 **이 실행의 첫 측정 면적(1888) 대비 0.75~1.35배**로 정했는데, 첫 측정이 자연 변동의 낮은 끝이었다. 같은 블록의 면적은 위치·방향(옆면이 보이는 정도)에 따라 달라진다. 저장된 놓인 블록 사진 184장에서 면적 1872~3207(중앙 2421), 긴/짧은 변 1.47~2.44였다(비 1.7배). 설계 시 관측 범위를 2300~3000으로 어림해 하한 1888을 고려하지 않았다.

## 수정

- 한계를 저장 사진 분포 기반 **절대 값**으로 바꿨다: 면적 1500~3800, 긴/짧은 변 ≥ 1.4(`SHAPE_AREA`, `SHAPE_ASPECT_MIN`). 정상 변동이 통과하고 면적이 크거나 정사각에 가까운 이상 형상이 걸리는 것을 Fake 시험 두 개로 확인했다. 전체 `pytest` 348 passed.
- 이 한계가 실제로 세워진 블록을 잡는다는 보증은 없다(세워진 블록 사진이 없음). 일반 안전 점검의 거친 한계다.

## 교훈

- 점검 한계는 **첫 측정 한 점이 아니라 저장된 자료의 분포**로 정한다. 새 점검을 넣을 때는 기존 사진 전체에 먼저 돌려 오경보를 센다.
- 오경보로 멈추는 것은 안전 쪽 실패이지만 무인 실행의 흐름을 끊는다.
