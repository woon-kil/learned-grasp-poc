## 0. 이 문서의 위치 (먼저 읽을 것)

이 플랜은 정본 플랜 v2.2와 `AGENTS.md`가 정한 **프로젝트 조건을 풀었을 때** 2026-11 기준으로 가장 앞선 구성이 무엇인지 적는다. 조건 준수판과 비교하는 기준점이다.

- **이 저장소에서 그대로 실행할 수 없다.** 허용 자세 표 밖의 연속 관절 명령은 AGENTS 4번 위반이다. 실행하려면 사용자가 (a) 별도 저장소를 만들거나 (b) AGENTS를 개정해야 한다. 이 문서는 둘 다 하지 않는다.
- 풀지 않는 것: **사람 안전.** 감독자 상주, 전원 차단 수단, 무인 수집 금지는 유지한다. 이것은 프로젝트 조건이 아니라 장비 조건이다.

## 1. 목적

저가 팔에서 「언어로 지정한 물체를 집어 올리기」를 최신 방법 두 갈래로 구현해 같은 시험에서 비교한다.

- **트랙 P (정책 학습)**: 사전학습 VLA를 미세조정해 영상·언어 → 연속 행동 청크를 낸다.
- **트랙 M (모듈형)**: 마커 없는 자동 보정 → 개방 어휘 분할 → 6-DOF 파지 생성 → 운동 계획.

## 2. 현재 상태와 목표 상태

| | As-Is | To-Be |
| --- | --- | --- |
| 팔 | DOFBOT 5축, SDK 정수 각도, 반복성 G0b·G0c로 확인 | 기본안: SO-101 쌍(LeRobot 기본 지원). **SO-101도 5관절+그리퍼다**(LeRobot 문서: 팔로워 STS3215 6개, shoulder pan·shoulder lift·elbow flex·wrist flex·wrist roll·gripper). 즉 DOFBOT과 같은 급이고, 얻는 것은 자유도가 아니라 **리더 암·생태계·연속 제어**다. 6-DOF 파지를 온전히 쓰려면 6관절 팔을 따로 골라야 한다(X2) |
| 카메라 | Gemini 335L 고정 RGB-D | 335L 고정 + 손목 카메라(DaBai 또는 소형 USB) |
| 제어 | 표 이산 자세, 개루프 | 행동 청크 연속 제어, 폐루프 |
| 학습 | 미구현 | π0.5 action-expert 미세조정, ACT 대조군 |
| 연산 | Mac M4 Max 48 GB, p620 RTX 3090 24 GB | openpi README: 추론 >8 GB, **LoRA 미세조정 >22.5 GB, 전체 미세조정 >70 GB**. 채택한 action-expert 미세조정의 요구량은 표에 없다(미확인). LoRA는 쓰지 않으므로 22.5 GB는 근거가 아니다 → 3090으로 될지 미정, X1에서 실측. 안 되면 클라우드 GPU |

## 3. 접근 방법

| 안 | 판단 | 근거 |
| --- | --- | --- |
| **트랙 P: π0.5 action-expert 미세조정** | 채택 | SO-101(DOFBOT과 같은 5관절급) 비교 연구(arXiv 2610.37170, 단일 저자·작업 1종)에서 12~25 시연 구간 최강(검색 요약). 초록에서 LoRA 4/110 vs action-expert 130/200 확인 → **LoRA 쓰지 않음** |
| ACT | 트랙 P 대조군 | 같은 연구에서 100 시연 이상이면 ACT가 앞섬 |
| SmolVLA | 제외 | 같은 연구 초록: 47% 에피소드에서 팔이 출발하지 않음. 약 50% 정점은 검색 요약. 다른 실험실 블로그(2차)에서도 하강만 반복하는 실패 |
| **트랙 M: Kalib/ARC-Calib + 분할 + GraspGen** | 채택 | 보정은 학습·메시 불필요(Kalib), GraspGen은 점군 → 6-DOF 파지·신뢰도 |
| 실기 RL 미세조정 | 보류 | 저가 팔 + 무보정 + 실기 RL을 결합한 2025~2026 사례를 찾지 못함. 무인 수집 금지와 상충 |

자기 수집(정본의 핵심 아이디어)은 **트랙 P의 데이터 증폭기**로 남긴다. 사람이 시연한 「집기」를 시간 역전한 「놓기」로 리셋을 자동화하고, 성공한 재집기를 추가 시연으로 쓴다. 감독자는 상주한다.

## 4. 구현 단계

### 4.0 Spike (쓰기 0건 또는 최소)

| ID | 확인할 가정 | 실패 시 |
| --- | --- | --- |
| X1 | π0.5 action-expert 미세조정 메모리 요구량(openpi 설정·코드 확인 후 1 step 실측)이 RTX 3090 24 GB에 들어간다 | 클라우드 GPU 비용 산정(≥$1이면 사용자 확인) |
| X2 | 팔 선정: SO-101 쌍(5관절, 저가) vs 6관절 팔. 구매·조립 일정과 비용 | 트랙 P를 DOFBOT 연속 제어로 축소(R15 J4 `None` 위험 재평가 필요) |
| X3 | GraspGen 저장소의 입력 좌표계 요구(보정 필수 여부) | 기하 자세 추정으로 대체 |
| X4 | Kalib 기준점이 대상 팔에서 추적된다 | ARC-Calib 또는 체커보드 |
| X5 | 개방 어휘 분할 모델(후보: SAM 2 계열 + 텍스트 그라운딩)이 335L 영상에서 블록·미학습 물체를 분할 | 색 분할로 축소, 다물체 범위 축소 |

### 4.1 하드웨어·안전

1. 팔로워·리더 조립, LeRobot 드라이버로 관절 한계 확인.
2. 소프트 안전: 관절 한계, 속도·가속 한계, 작업 공간 상자, 행동 청크마다 한계 검사 후 전송. 이산 표는 쓰지 않지만 **한계 밖 명령은 전송 전 차단**한다.
3. 전원 차단 거동을 빈 그리퍼로 먼저 확인(정본 G0a와 같은 원칙).

### 4.2 트랙 M

1. 자동 보정(X4 결과의 방법) → 카메라→기저 변환. 세션 시작마다 재검증.
2. 언어 지정 → 분할 → 물체 점군 → GraspGen 후보 → 도달 가능성·충돌 필터 → IK → 궤적.
3. 5관절 팔(DOFBOT 또는 SO-101)에서 GraspGen 6-DOF 후보 중 도달 가능한 비율을 보고. 6관절 팔을 고른 경우에만 5관절과 비교한다(조건 준수판과의 다리).

### 4.3 트랙 P

1. 원격조작 시연 수집: 25 → 50 → 100 → 200 단계. 단계마다 평가해 곡선을 그린다(외부 연구와 같은 형식).
2. 자기 수집 증폭: 성공한 정책 실행을 감독 하에 추가 데이터로. 실패도 보존.
3. 입력: 고정 RGB + 손목 RGB(+ 선택적으로 depth). 출력: 관절 행동 청크.
4. π0.5 action-expert 미세조정과 ACT를 같은 데이터로 학습.

### 4.4 시험

| 시험 | 조건 | 대상 |
| --- | --- | --- |
| E1 | 학습 물체, 사람 배치 | 트랙 P, 트랙 M, ACT |
| E2 | 방해물·조명 변화 | 같음 |
| E3 | 미학습 물체(언어 지정) | 같음 |

N과 합격선은 시연 수집 시작 전에 고정한다. 재시도 금지, 분모 전체, Wilson 95% 구간 병기, 미완료는 미완료로(정본 §7 원칙 계승).

## 5. 영향 받는 파일

이 저장소 파일은 바꾸지 않는다. 실행을 결정하면 새 저장소에서 별도 플랜으로 시작한다.

## 6. 검증 계획

- Spike X1~X5 각각 수치 기준을 실행 전에 커밋.
- 트랙 P: 시연 수별 성공률 곡선, 실패 단계(접근·파지·운반) 분류.
- 트랙 M: 보정 재투영 오차, 파지 후보 중 실행 가능 비율, 성공률.
- 두 트랙 비교는 같은 시험표·같은 세션 순서 무작위화.

예상 성능 수치는 적지 않는다. 외부 연구 수치는 다른 팔·다른 작업의 값이다.
