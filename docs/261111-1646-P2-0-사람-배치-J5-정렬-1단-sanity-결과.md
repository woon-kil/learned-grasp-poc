## 1. 결과 (실행 출력)

`runs/P2-0/p1.jsonl`(gitignore), `scripts/p2_plan.py`, `scripts/p2_summary.py runs/P2-0` 출력:

```
p2-01 측정(사람이 놓음): r_index 2, J1 96, 블록 방향 d +0.2°, J5 90, ψ_pred 0.1°   (첫 놓기는 목표(J1 93 부근)가 아니라 마커 왼쪽(J1 69, 범위 밖)이라 쓰기 없이 다시 놓게 했다)
p2-04 측정(사람이 놓음): r_index 4, J1 86, 블록 방향 d +24.1°, J5 110(목표 J5 106)

p2-01: J5 90 (|J5−90| 0), 결과 success, 서보 149, 집기 전→도로 놓은 뒤 블록 각도 변화(비틀림) +8.1°
p2-04: J5 110 (|J5−90| 20), 결과 success, 서보 150, 집기 전→도로 놓은 뒤 블록 각도 변화(비틀림) -1.1°

완료. 세션 쓰기 누적 22회.
```

- **2/2 성공**, 쓰기 **22회**(예상 22), 이상 없음. 사람 접점은 시도당 「놓았다」 한 번(첫 놓기는 위치가 목표와 달라 한 번 더).
- **J5 확인 상승이 동작했다**: p2-01(편차 0)은 처음이라 확인, p2-04(편차 20)는 이전 확인 최대 0보다 10° 이상 커서 확인을 요청했고 사용자가 확인했다. 기록 `runs/P2-0/j5_dev_confirmed` = 20.
- **비틀림 사진이 찍혔다**(`*-putback`).
- J5 110(편차 20°)에서 정렬 집기가 성공했다. 손 yaw 모델의 J5 극단 쪽 첫 실기 확인이다(표본 1개).

## 2. 비틀림 지표의 읽기 (한계)

비틀림은 집기 전 블록 각도 대비 도로 놓은 뒤 각도의 변화이므로 **닫는 동안 손이 돌린 각도와 도로 놓는 순간 블록이 돌아간 각도의 합**이다. p2-01은 J5 90에서 손 yaw 모델 예측(d_hand ≈ +0.3°)과 블록 방향(+0.2°)이 맞았는데도 +8.1°가 나와, 놓을 때의 흔들림(CH-3에서 본 놓인 방향 표준편차 3.4°보다 큼)이거나 모델·측정 오차다. p2-04는 −1.1°로 작았다. 표본이 2개라 해석하지 않는다. 본 실행에서 J5 편차별 분포로 본다.
