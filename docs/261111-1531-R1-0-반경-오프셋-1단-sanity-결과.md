## 2. 오프셋 놓기 보정 부호 확인 (사전 고정 기준)

놓인 블록의 L1 반경 위치(`r_cont`)를 공칭 행의 `r`와 비교했다(`chain-002·003·004` 사진, 마지막은 종료 시 사진):

```
chain-001(Δ+0): 공칭 행 6(r 149.6, J1 78), 손 행 6(r 149.6) → 놓인 블록 L1 r 148.6, J1 77.7: 공칭 대비 -0.9 mm, 손 행 대비 -0.9 mm, 놓인 뒤 d -1.2°
chain-002(Δ+3): 공칭 행 6(r 149.6, J1 102), 손 행 9(r 165.1) → 놓인 블록 L1 r 147.0, J1 101.1: 공칭 대비 -2.6 mm, 손 행 대비 -18.1 mm, 놓인 뒤 d -2.7°
chain-003(Δ-3): 공칭 행 6(r 149.6, J1 79), 손 행 3(r 134.1) → 놓인 블록 L1 r 150.2, J1 79.0: 공칭 대비 +0.6 mm, 손 행 대비 +16.1 mm, 놓인 뒤 d +1.5°
```

기준: 공칭 ±5 mm 안이면 보정이 맞고, 손 행(약 ±15 mm) 쪽이면 틀린 것. **결과는 공칭 −2.6 mm(Δ+3)와 +0.6 mm(Δ−3)로 ±5 mm 안이다. 쥔 블록이 턱 안에서 제자리를 지키고, 놓는 손 행 = 공칭 + Δ가 맞다.** 본 실행은 이 규칙 그대로 간다.

## 3. 기계적 합격 확인

J5와 오프셋 행으로 실제 쓰기가 나갔다(집는 행 9·3, J5 83·86·81·90), 오프셋 확인이 약속대로 걸렸고, 기록 필드(`offset`, `r_l1`, `r_pick`, `place_row`)가 채워졌다. 놓인 뒤 방향 d는 −1.2, −2.7, +1.5°다(놓기 정렬 예측 부근, 표본 3개).
