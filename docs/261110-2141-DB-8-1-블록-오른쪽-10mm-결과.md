# DB-8-1 블록을 오른쪽으로 약 10 mm 옮겼을 때 마커 영상 위치 (결과)

2026-11-10 KST. 플랜은 `docs/261110-2110-DB-8-플랜-승인요청.md`다. 승인: 「승인, 간격 10밀리 잼, 시작확인, 그리퍼 서보 20.7도씨」. 쓰기 3회(`dabai-view --r-index 0 --hover-only`), 닫지 않음, `grasp` 없음. 승인 파일 `runs/DB-8-1/approval.json`(gitignore).

## 1. 플랜에서 바뀐 점 (측정 방식)

- 플랜의 e, g(중심선 거리, 틈) 측정은 손으로 믿을 만하게 재기 어려워 **정지 방식**으로 바꿨다. 블록 오른쪽에 포스트잇 더미를 놓고 블록을 그쪽으로 밀었다. 사용자가 잰 간격은 **10 mm**다.
- 포스트잇이 완전한 정지 막대가 되지는 못했다. Gemini 사진에서 블록 오른쪽 면이 포스트잇 위로 약 5 mm 올라탔다(`data/db8/place1-pushed/`, gitignore). 이동량은 한 값으로 단정하지 않고 아래 세 가지를 같이 적는다.
- 회차 3(베이스 쪽 5 mm)은 블록 윗끝이 로봇 베이스 가장자리 바로 앞이라 보류했다.

## 2. 측정값 (고정 절차, 한 번)

| 항목 | DB-7(기준 자리) | DB-8-1(오른쪽으로 이동) | 변화 |
| --- | --- | --- | --- |
| 블록 마커 id 7 중심 (열, 행) | (378.0, 411.8) | (334.8, 401.0) | **Δ열 −43.2, Δ행 −10.8** 화소 |
| id 7 변 길이 | 94.8 화소 | 94.3 화소 | −0.5 |
| id 7 회전(첫 변 각도) | −177.6° | −177.6° | 0 |
| 보드 마커 id 1 중심 (열, 행) | (363.0, 256.8) | (363.2, 256.2) | Δ 0.2, −0.6 화소 |
| id 7 영상 안 코너 | 4/4 | 4/4 | |
| 높이(고정 절차, 모호성 해 선택) | 38.7 mm | 35.8 mm | 두 값 모두 실제 높이 확인 불가 |

- 이동량 세 가지: 사용자가 잰 간격 **10 mm**, Gemini 사진의 마커 id 7 이동 약 **10.5 mm**(1.24 화소/mm로 환산, ±1~2 mm), 포스트잇 위로 올라탄 양을 고려하면 10 mm 이상일 수 있다.
- 화소/mm: id 7 변 94.5 화소가 25 mm이므로 마커 평면의 스케일은 약 **3.8 화소/mm**다. 이동량을 10 mm로 보면 열 방향 **4.3 화소/mm**이고, 영상으로 환산한 이동은 약 11.4 mm다. 행 방향 10.8 화소는 약 2.9 mm에 해당한다.
- **행 방향 변화**: 블록이 앞뒤로 약 3 mm 밀렸을 가능성이 있다. 블록은 보드 마커 id 1에 거의 닿은 자리였다. 마커 회전이 없으니 평행 이동이다. 원인은 이 측정으로 구분하지 못했다.
- **카메라 반복성**: 보드 마커 id 1이 0.2~0.6 화소만 움직였다. `park → hover(r_index 0)` 경로의 영상 위치 반복성이 이 한 쌍에서는 1 화소 안이다(DB-7의 J2 93, 이번 종료 후 J2 91이었는데도).
- 모델 예측 화소/mm와의 비교는 **아직 하지 않았다**(분석 후 비교 규칙, 별도 단계).

## 3. 한계

- 이동량이 정확히 한 값이 아니다(위 세 가지, 10~11.4 mm). 화소/mm는 4.3 안팎이고 ±10% 정도로 본다.
- 한 회차, 한 방향이다. 왼쪽 이동(회차 2)과 비교해야 선형성과 대칭을 볼 수 있다.
- 높이 값(38.7 → 35.8 mm)은 IPPE 법선 모호성 때문에 신뢰하지 않는다.

## 4. 관찰 (사용자)

이동 중 접촉·이상음·떨림·케이블 걸림: **이상 없음**(사용자 답변). 그리퍼 서보 온도: 시작 20.7 ℃, 끝 **20.5 ℃**.
