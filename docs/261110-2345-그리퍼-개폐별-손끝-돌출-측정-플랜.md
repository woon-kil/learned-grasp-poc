# 그리퍼 파지 정도별 손끝 돌출 측정 플랜 (승인 요청 초안)

작성: 2026-11-10 KST. **승인 전이다. 팔에 명령을 보내지 않았고 코드도 바꾸지 않았다.** 사용자 요청: 「파지 시 그리퍼의 파지 정도에 따라 손끝 돌출/후퇴 정도를 측정해야 한다.」

## 1. 목적과 이유

- L1(손-눈 보정)과 파지 높이는 **닫은 손끝** 기준이다(HW5). 손끝은 열림 정도에 따라 앞뒤로 움직인다.
- 현재 기록은 서로 맞지 않는다: `HARDWARE-FACTS.md`는 「SDK 100에서 블록 접촉까지 16~20 mm 돌출」, URDF 모델 계산(`scripts/gripper_protrusion_model.py`, `docs/*H2-0-손-외형-Gemini-결과.md` §4)은 같은 구간(간격 40→30 mm)에서 약 3 mm이고 URDF 범위 전체(완전 열림→완전 닫힘)에서 약 30 mm다. **실측으로 정해야 한다.**
- 결과는 SDK 열림 정도 → 손끝 앞뒤 위치(mm) 표다. 사용처: ① 파지 높이 안전 마진(HW5, 작업대 누름) ② 영상 속 손 마커와 파지 지점의 어긋남 보정(H2-1, H3) ③ 블록 폭별 접촉 시점의 손끝 위치.

## 2. 설계

- **자세**: 표의 `r_index 4`, J1 90, J5 90의 **grasp 자세**(H2-0과 같다). 열린 손 사진은 H2-0의 `data/h2/place/grasp.png`와 같은 자세·카메라라 비교 기준으로 쓸 수 있다. 시험은 거기서 다시 찍는다.
- **빈 손**, 블록 없음, 보드 구역 비움(H2-0과 같은 치움).
- **열림 정도 단계**: SDK 100(열림, 기준), 115, 130, 145, **155(닫힘 = 구성 `close_sdk`)**. 모두 `open_sdk`~`close_sdk` 사이이고 기존 허용 범위 안이다. 각 단계에서 정지, Gemini 한 장, 다음 단계.
- **왜 안전한가**: 닫힘(155)은 이미 grasp 자세에서 허용된 동작이고 `close-check`(빈 손 닫기)로 시험했다. 중간 단계는 손끝 돌출이 닫힘보다 작으므로 작업대 접촉 위험이 닫힘 이하다(돌출은 열림 정도에 단조 증가한다고 보는 가정이다. 이 가정은 URDF 모델에서만 확인했고 실측은 이 시험이다).
- **코드 변경(승인 후)**: `check_grip`에 중간 정도 동작을 추가한다. 새 동작 `level:<sdk>`는 ① grasp 자세에서만 ② `open_sdk ≤ sdk ≤ close_sdk` 범위에서만 ③ 빈 손(`holding False`)에서만 허용한다. `session.py`에 `grip-sweep` 명령(`--r-index`, `--levels` 기본 위 5단계, 단계마다 신호 파일 대기, 대기 상한 300초 초과 시 열고 hover·park로 복귀)을 둔다. 닫힘 한도(`CloseWatch`)는 115 이상에서 시작해 마지막에 open 때 멈춘다. Fake 시험: 범위 밖·hover·holding 거부, 쓰기 수, 신호 없이 안 움직임, 한도 만료 시 복귀. `pytest` 전체. 변경 파일 `src/learned_grasp/safety.py`, `arm.py`, `session.py`와 `tests/`(약 50행 추산).
- **쓰기 추산**: park, hover, grasp 3회 + 그리퍼 단계 4회(115~155) + open 1회 + hover, park 2회 = **약 10회**(실제 수는 Fake 시험에서 확인해 승인 요청서에 적는다).
- **닫힘 시간**: 단계마다 Gemini 한 장에 약 20~40초라 닫힘 상태 총 약 2분이다. `close-check`의 유지 상한은 60초였다. 한도는 승인 요청서에서 정한다(미정).

## 3. 분석 (실행 전 고정)

- 각 단계 사진에서 **검은 손가락 끝의 영상 위치**(어두운 덩어리의 아래 끝, 두 손가락의 중점)를 같은 절차로 잰다. 보드 마커 id 1의 화소를 위치 기준으로 쓰고 카메라 이동을 확인한다.
- 돌출 mm = (손끝 영상 이동 화소) / (작업대 평면 근처 축척 약 1.24 화소/mm, 높이 차이로 ±10% 불확실). 손가락 간격 화소도 함께 재어 SDK 100의 간격 37~43 mm(HARDWARE-FACTS)와 대조한다.
- 결과 표: SDK 단계 × (손끝 영상 위치, 간격 화소, 환산 돌출 mm). 모델(URDF)과 `HARDWARE-FACTS`의 16~20 mm와 **분석 후** 비교한다.
- 한계: 한 번씩, Gemini 0.8 mm/화소, 높이 시차(손끝은 table 위 약 20 mm 근처), 손가락 끝 정의가 사람이 정한 분할이다.
