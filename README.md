# learned-grasp-poc

저가 5축 팔(DOFBOT Pro)과 고정 RGB 카메라(Gemini 335L)에서, 명시적 손–눈 변환을 추정하지 않고 로봇이 직접 모은 데이터로 영상→파지 명령 대응을 학습해 물체를 집어 올리는 것을 실증하는 PoC다.

> **상태: 구현 준비 단계. 실기 결과 없음, 모든 성능 값은 미측정이다.** 진행은 [PROJECT-STATUS.md](PROJECT-STATUS.md)를 본다.

## 아이디어

보정 대신 반복 정밀도를 쓴다.

1. 로봇이 물체를 허용 자세 `q`에 놓고 물러나 촬영한다.
2. 같은 `q`로 돌아와 다시 집는다. 성공하면 그 이미지의 정답은 「검증된 파지 명령 `q`」다.
3. 모델이 `이미지 → 명령`을 배운다. 추론값은 같은 표를 거쳐 실행된다.

카메라 파라미터, 실물 TCP, 손–눈 변환이 라벨에 들어가지 않는다. 대신 같은 명령의 반복 정밀도에 전적으로 의존하며, 이 전제가 성립하는지는 첫 실기 게이트(G0)가 판정한다.

## 검증 방식

시험은 실행 전에 계약을 고정한다. 사람이 시드로 만든 시험표대로 물체를 놓고, 재시도 없이 전체를 분모로 센다. 합격선은 T1 24/30이고 Wilson 95% 구간을 함께 보고하며, 고전 비전 기준선과 같은 시험표로 비교한다. 불합격도 결과로 남긴다. 상세는 [플랜](docs/261109-1017-learned-grasp-poc-플랜.md) §7이다.

주장하지 않는 것: 보정의 일반적 대체, 임의 물체 일반화, 산업 수준 신뢰성.

## 개발

```bash
uv sync
uv run pytest -q   # 장치 없이 실행된다
```

실기 실행 절차는 [G0-RUNBOOK](docs/G0-RUNBOOK.md)이고, 사용자 승인과 전원 차단 담당자가 필요하다.
